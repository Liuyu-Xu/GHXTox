# 溶血环境信息：纯计算可行性与首轮小模型结果

日期：2026-10-25。没有安排湿实验，没有重训GHXTox；本地已完成公开数据整理与40次固定配置的小模型训练。

**结论：公开数据足够做纯计算探索，但本轮仅加入浓度、红细胞种类，没有得到稳定、明显的预测提升。现在不值得直接为环境模块投入大模型重训。** 此结论仅适用于本轮数据、特征和轻量模型，不等于环境在生物学上不重要。

## 1. 数据已经整理到什么程度

使用[Hemolytik 2.0官方完整下载](https://webs.iiitd.edu.in/raghava/hemolytik2/down_seq.html)，原始13215条记录、6849条序列。数据库记录有论文标识、序列、MAP修饰表示、末端、手性、活性描述和测定对象。时间、温度没有结构化列。[官方说明](https://webs.iiitd.edu.in/raghava/hemolytik2/usr_guide.html)与原始下载均保留。

| 本轮严格筛选后 | 数量 |
|---|---:|
| 可用于固定浓度溶血比例回归的记录 | 3380 |
| 不同氨基酸序列 | 1792 |
| 区分末端后的分子形式 | 1839 |
| 来源PMID标识 | 563 |
| 编辑距离序列群 | 823 |
| 同一分子形式有跨红细胞来源记录 | 83 |
| 同一PMID、同浓度下有跨来源记录的分子形式 | 41 |
| 上述同文献同浓度比较块 | 61，合计134条记录 |

筛选只保留5–50残基、标准氨基酸、L型线性肽、无额外MAP残基/环化标签、可解释的游离/乙酰化N端及酸/酰胺C端。只解析明确的“溶血百分比 at 确切摩尔浓度”；近似号、大小于号不强行变成精确值。μM与mM按单位换算，质量浓度没有擅自用不完整分子量换算。

3447条通过初步范围过滤，44条同记录重复被折叠；另10个已记录条件相同但数值冲突的组（23条）暂不进入本轮模型，其原始值保留。没有删除原数据库或GHXTox数据。

人红细胞记录2420/3380，占71.6%；pH可提取190/3380，占5.6%，本轮只记录不拟合。温度、暴露时间、缓冲液、红细胞密度缺少统一字段。因此这是一轮**浓度/测定物种条件模型**，不称完整环境模型。统一家族标签未提供，823个序列群不能冒充823个生物学家族。

MAOMAO既有定量附件只有169条、166序列，且混有HC50/LC50/LD50/MHC，并缺少充分条件字段。本轮直接回到更完整的来源数据库，避免把这169条误当成全部可用溶血实验。

## 2. 小模型怎么比较

预测目标是：**在某个明确浓度下，溶血比例是多少（0–100%）**。浓度是处理条件，允许作为输入；HC50、活性文本、PMID、肽名、来源说明、实验结构、数据库“非溶血”标签都不作为特征。

相同固定ExtraTrees模型和参数，比较四组：

1. 肽信息：氨基酸组成、二肽组成、长度、电荷近似、疏水性、理想螺旋疏水矩、末端形式。
2. 肽信息＋浓度。
3. 肽信息＋浓度＋数据库报告的红细胞种类。
4. 只看浓度＋红细胞种类，用于检查条件字段是否只是来源捷径。

没有微调ProtT5、Mamba或三维模型，没有超参数搜索。本轮“肽信息”是轻量理化/组成特征，**不是GHXTox本体**。

验证采用两套五折：

- 按序列相近群分组。同一骨架的不同末端、浓度、对象都在同组。近似关系是单位代价全局编辑距离≤最长序列长度的20%，再取连通群；它不是CD-HIT标准同一性定义。
- 更严格的跨PMID评估，同时清除训练集中与评估集共享序列群的记录。每折额外清除479–581条，避免同肽或近亲跨论文进入两侧。

PMID是数据库给的来源标识，不保证每个都是独立原始实验。评估按每种分子形式等权，避免同肽多个剂量点压过其他肽。没有依据测试集预测调整任何选择。

## 3. 结果：环境代理变量的增益很小

平均绝对误差单位是**溶血百分比的百分点**，越低越好。例如真实20%、预测42%，该条误差为22个百分点。

| 输入 | 序列群分组：平均误差 | 跨PMID并清除近亲：平均误差 |
|---|---:|---:|
| 肽信息 | 22.97 | 22.71 |
| 肽信息＋浓度 | 22.77 | 22.73 |
| 肽信息＋浓度＋红细胞种类 | 22.61 | 22.54 |
| 只用浓度＋红细胞种类 | 25.54 | 26.10 |
| 只预测训练集加权中位数 | 24.13 | 24.06 |

在严格跨PMID评估中，额外加入红细胞种类，误差下降**0.19个百分点**；按序列群配对重采样的95%区间是**−0.12到0.54个百分点**，覆盖零。本轮不能确认稳定改善。该区间基于已冻结的折外预测，未包含所有重新训练及实验测量的不确定性。

完整模型的严格评估R²约0.065，说明这套简单特征对数值差异的解释能力仍弱。它略好于常数参考，但远不是已经实用的定量预测器；不能据此反推所有更好表征也学不到环境作用。

## 4. 同肽跨物种面板给出什么线索

61个“同PMID＋同分子形式＋同浓度（及已报告pH）”比较块中，20个块的溶血数值跨度≥10个百分点；全部块的跨度中位数为2个百分点。可观察到条件相关差异，但它们不是已经控制所有变量的湿实验配对，时间、温度等仍未知。

仅在该134条、41种分子形式面板上看冻结预测：

| 输入 | 序列群分组误差 | 严格跨PMID误差 |
|---|---:|---:|
| 肽信息＋浓度 | 21.29 | 22.21 |
| 肽信息＋浓度＋红细胞种类 | 21.11 | 23.25 |

环境项在严格跨来源面板里反而变差，进一步说明当前增益不稳。不根据此结果继续调参数或挑选好看的物种子集。

## 5. 与GHXTox错题的关系

本轮记录与GHXTox训练集精确重叠68条序列，与历史测试序列重叠8条，故整套数据不能称全新独立外部测试。这里只读取序列身份来登记重叠，不读取历史测试预测。

对应训练模型的原广义毒性标签和判断，68序列对应73种分子形式：63种原TN、8种FN、2种FP，没有TP。**这些不是重新按溶血终点定义的正确/错误**。在本轮严格范围内，仍未找到原GHXTox同记录条件下的TP/FN配对。因此不能把本轮环境回归的结果等同于已经纠正Na1b等GHXTox错题。

这并不妨碍纯计算研究：我们已直接测试公开条件记录的预测增益，没有把“必须找到完美对照”当作小模型实验的阻碍。

## 6. 下一步决定

**完成了第一轮纯计算验证，暂不扩大环境网络。** 数据可用，结果不支持立即大规模重训。

如继续，优先顺序是：

1. 固定本轮数据与分组，换成已有/可获得的冻结蛋白语言模型表征，再比较是否加入浓度和对象。先判断简单序列特征不足是否掩盖了增益，避免同时换数据、网络和评估规则。
2. 若公开来源有可批量获取的时间、温度、pH字段，再补入；不安排生物实验，不逐条无止境追溯，也不猜填。
3. 只有在相同严格划分中出现稳定的额外增益，再考虑对GHXTox训练分支进行条件建模。普通条件拼接本身不能宣称方法创新；当前也未验证膜构象机制。

## 7. 文件及验证

- `sources/Hemolytik2_complete_data.csv`：官方原始快照，未改写。
- `run_pilot.py`：过滤、旁表、编辑距离分组、40次训练及配对比较，可重跑；`protocol.json`记录固定配置。
- `model_records.json`、`coverage.json`：模型记录与数据覆盖。
- `same_paper_dose_cross_species.json`：61个跨对象比较块，逐条附缺失条件提示。
- `ghxtox_training_links.json`、`matched_GHXTox_TP_FN_blocks.json`：训练身份关联；后者当前为空。
- `fold_metrics.json`、`pilot_summary.json`、`pilot_predictions.json`：全部折、全部模型结果。
- `paired_comparisons.json`、`cross_species_panel_metrics.json`、`constant_baselines.json`：不确定性、同肽面板与常数参考。
- `verification.json`：每套划分每个模型均覆盖全部3380条，训练/评价序列群不重叠；严格划分PMID也不重叠；冻结GHXTox训练表SHA256前后一致。

数据库本身可能含修饰、单位或实验归属错误；此前Oxyopinin更正就是实例。本轮是公开数据条件预测的计算探索，不是逐条原文确认的实验真值集，不是GHXTox独立性能验证。无需服务器和GPU，未使用收费算力。
