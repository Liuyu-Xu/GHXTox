# 代表性错分样本的实验依据核查（2026-10-25）

本轮整理4条训练错分样本、3条已有组成匹配对照和2条背景对照，共9条。得到的主要结论是：Na1b 有直接实验支持；Ectatomin A/B 的输入与原实验分子不一致；H1/H2 的活性有依据，但化学形式仍待核实。现在还不能据此决定加权或改网络。

## 1. 模型究竟错在哪里

TP表示相对原标签判对，FN表示原标签有毒却判无毒。它们不是本轮重新确认的实验真值。完整逐样本结果见同目录 `sample_table.md` 和 `sample_audit.json`。

| 错分样本 | 1D / 3D / 融合 | 原实验依据与本轮结论 | 下一步 |
|---|---|---|---|
| peptide_249，Na1b | FN / FN / FN | 精确序列对应有直接细胞毒性、溶血测量的合成肽。可以作为可靠难例线索 | 扩展同机制、同实验终点的正确及错误样本，检验是否有稳定共性 |
| peptide_201，Ectatomin A | TP / FN / FN | 原文测的是A+B连接的完整毒素。本轮没有找到孤立A链直接毒性测量 | 先区分单链与完整组装体，不能直接解释为3D不理解毒性 |
| peptide_251，H1C/H1U | TP / FN / FN | 原摘要支持溶血及人纤维细胞效应；具体修饰、时间和剂量单位未全部核实 | 优先核对原文方法、表格及分子形式 |
| peptide_424，H2C/H2U | FN / FN / FN | 与H1来自同一研究，证据限制相同；本轮没有合格的既有匹配对照 | 保留待核实，不强配对照 |

其中201和251体现一维/三维意见不同。249和424是两支都漏判。上述分类沿用冻结OOF各自阈值，不使用统一0.5重新定义分歧。

## 3. 对照也需要查证

| 对照 | 如何配对 | 核查结果 | 能否当作可靠标准 |
|---|---|---|---|
| peptide_308，Cupiennin-4a | 与249的既有组成匹配对照 | B3EWV6有序列及C端酰胺化实验注释；本轮读到的[原论文摘要](https://pubmed.ncbi.nlm.nih.gov/22672445/)主要支持毒液成分鉴定，未确认本条肽直接毒性测量 | 目前不能，仅保留原标签TP含义 |
| peptide_19，hhe53 | 与201的既有组成匹配对照 | P0CI21无FUNCTION测量注释；[相关原研究](https://doi.org/10.1371/journal.pone.0087648)的Augerpeptide Hhe53小节及Fig.10说明其成熟序列来自cDNA预测。本轮未找到直接毒性测量 | 不能作为已证实有毒的实验标准；也不应反过来认定无毒 |
| peptide_139，Antibacterial protein 2 | 与251的既有组成匹配对照 | P11698有实验来源溶血注释，关联[原研究](https://doi.org/10.1042/bj2520087)；同序列Q4L5M2为相似性推断。原摘要有N端甲酰化线索；具体溶血条件尚未核实 | 有实验来源线索，但尚非完整条件匹配的标准 |
| peptide_74，Ectatomin B | 201的同分子另一亚基，非组成匹配对照 | 模型判对，但它同样是完整双链毒素的一部分 | 不能据A错/B对认定B更有毒 |
| peptide_4117，Na1a | 249的家族背景对照，原标签0，模型TN | P0DSM2的活性FUNCTION来自P82423相似性推断，没有本条直接无毒证据 | 不能认定可靠阴性，也不能认定标签错误 |

组成匹配仅表示长度、电荷、疏水性等在此前规则内接近，不能自动保证实验对象、机制、物种和证据质量相同。此次抽查说明此前“没有发现某类标记”不等于证据充分。hhe53论文对另一个物种同源转录本的功能疑问，不能直接作为P0CI21无毒结论。

## 4. 现在最值得做的事

1. 优先扩展Na1b这类有直接实验支持、模型仍漏判的膜活性肽；同时寻找相同终点下判对的样本。先判断共同特点是否跨家族存在。
2. 补齐H1/H2原文的修饰与单位。拿到之前，把甲酰化列为待检验因素，不直接给模型加修饰模块。
3. 给多链毒素单独记录“实际测试分子”。Ectatomin适合提示输入边界问题，目前不宜作为孤立单链毒性能力的正反例。
4. 证据可靠、同类样本数量够且规律稳定后，再比较普通难例加权与生物学特征改动；不确定标签不能因为模型判错就加大权重。

这些是研究优先级，不是已验证的致错机制。此次样本按已有错误队列选择，数量小，不能计算全数据集噪声率或断言某机制导致错误。

## 5. 溯源、限制和文件

- `sample_audit.json`：9条样本原序列、原标签、冻结预测、角色与审查结论，原标签独立保存。
- `sample_table.md`：9条样本的易读对照表。
- `assay_evidence.json`：按实验终点记录证据、条件、位置与未知项。
- `sources/Na1b_passages.json`与`Na1b_nci_fulltext.json`：NCBI BioC原文提取；后者实际为XML，扩展名是下载时遗留。表格来源是机器提取文本，未完成PDF视觉复核；部分正文有OCR字符异常。
- `sources/ectatomin_primary_search.json`：出版商页面被网络工具索引的全文文本；直接HTTP访问受限。`ectatomin_web_search.json`是一次未命中目标的搜索记录，不作为证据。
- `sources/P85219.json`等：UniProt记录快照。`supplementary_fetch_log.json`保存Hemolytik对应记录及原摘要API结果。
- H1/H2完整原文入口受限，未读到原始实验表格。control139的BioC返回非XML，未作为全文证据；其摘要与数据库注释已分别保留。本轮没有取得可用PDF，不声称核查完全部原文和补充材料。
- `verification.json`：9条身份对应、四病例、三既有匹配对照、H2未强配对照、输入OOF表前后SHA256一致。
- 训练OOF含历史校准与模型选择独立性限制，本轮只生成假设。Test1/Test2没有用于本轮方法开发。没有重训、删样本、重标、改权重或启动收费算力。
