# Figure output

Generated manuscript figures belong here. For each final figure, retain an
editable or vector source (`.svg` or `.pdf`) and a high-resolution raster
preview (`.png` or `.tiff`) using the same publication-facing base name.

`selective_prediction_risk_coverage/` is a complete training-OOF figure
package. It is not Test1/Test2 or external-validation evidence.

`selective_prediction_formal_current_default_v2/` is the authoritative formal
training-OOF package for the canonical current-default model. It adds five fixed
coverage points, an equal-coverage random-rejection control, paired bootstrap
uncertainty, a complete metric table, and publication-facing source data.
`selective_prediction_formal_comparison/` is historical v1 provenance only.

`selective_prediction_frozen_threshold_transfer_current_default_v2/` is the
authoritative Test1/Test2 transfer package. It applies the unchanged direct
OOF-derived margin cutoff,
reports natural benchmark coverage, compares against full prediction and
equal-count random rejection, and includes fixed-mask paired uncertainty. It
is established-benchmark transfer evidence, not a newly collected independent
dataset. `selective_prediction_frozen_threshold_test_transfer/` is historical
v1 provenance only.

`expert_disagreement_analysis/` is the authoritative Test1/Test2 1D--3D
complementarity package. It contains the four-group composition, reciprocal
class-specific rescue rates, five prespecified 3D-only versus 1D-only attribute
effects, exact tables, frozen source data, manifests, checksums, SVG/PDF, and a
600-dpi PNG. The conformer-availability association is explicitly treated as
length-confounded and is not evidence of a multi-conformer benefit.
