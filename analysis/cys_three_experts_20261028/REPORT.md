# 三个Cys专家与原GHXTox对照

用户指定三版：A原GHXTox历史五折OOF（三种子一维＋历史三维）；B按输入序列Cys数量选择一个小专家（0–1、2–5、≥6）；C将A与B的有毒概率各取50%。0–1/2–5/≥6分组依据看过的数据构思，仅探索，不能作为独立验证的确定边界。

小专家为复用冻结ProtT5 TriStat 3072维的标准化L2逻辑回归；每折只用本组训练角色，C参数由该组验证角色选择，Platt由独立校准角色拟合。保留原标签与疑点样本，组隔离先于Cys分组；无LoRA训练。B仅一维，A含三维，因此不是两个相同架构的容量消融。

## 评价边界

- 全部6387条训练数据每条作一次外层留出；五折组隔离并非序列相似度≤40%保障，先前多次做过相关探索。未使用Test1/Test2。
- A历史三种子与3D OOF以及全OOF Platt和阈值继承旧流程；A的校准/模型选择并非完全嵌套，可能使A占优势。C也继承这一限制，不能当新独立盲评。
- 小专家是冻结表征上的逻辑回归初筛，非完整GHXTox同架构单独重训；此结果只能说明本次实现和固定组合，不能否定更强专家、其他划分或融合。
- 旧疑点分层在metrics.json；未标记不等于可靠标签。全部检验未自动改模型或权重。
- 历史测试集已经用于假设生成，不再用其挑超参数或报告为盲测；下一步只有在训练内预先确定方案并独立外部评价后才能论证泛化。
