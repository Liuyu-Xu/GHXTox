# 溶血辅助监督能否提高毒性分类：固定小试验

日期2026-10-26。仅主Agent。**结论：当前配置没有通过继续门槛，不扩大、不继续调参、不并入GHXTox。** 已完成数据准备、30次小头分类拟合和独立重载核验，目标始终是原毒性分类指标，不再优化溶血曲线。

## 实际分类结果

以下为两个固定种子概率均值、固定0.5阈值、全部6387条训练OOF的结果。模型是冻结原始ProtT5均值特征上的新小头，**不是GHXTox完整LoRA-Mamba+3D模型的更新或性能表**；不能把本表与原GHXTox或旧TriStat/KD结果直接混比。所有三臂采用同一主任务训练/评价清单。

|方法|MCC|AUPRC|敏感性|特异性|FN|FP|
|---|---:|---:|---:|---:|---:|---:|
|只训练毒性分类|0.8184|0.9331|0.8685|0.9490|239|233|
|增加真实溶血辅助任务|0.8197|0.9357|0.8674|0.9503|241|227|
|增加打乱标签的辅助任务|0.8231|0.9346|0.8658|0.9532|244|214|

真实辅助任务相对毒性单任务：ΔMCC=+0.00131，联合序列群配对bootstrap95%区间[-0.00665, +0.00895]；ΔAUPRC=+0.00263。少6次假阳性，却多2次漏判。不能称稳定MCC提升，也不能因AUPRC点估计较高就更换主判断指标。

真实辅助相对打乱标签对照ΔMCC=-0.00343，95%区间[-0.01159, +0.00385]。打乱对照点估计更高不等于其统计上显著更好，但至少没有证明这次收益来自真实溶血信息。

两个种子的真实辅助MCC较各自单任务分别+0.00303、+0.00510；预定主结果是概率均值模型，不因种子均值/单种子更好而改用其他汇总。完整每折、每种子结果均保留。重采样按5220个联合序列群、2000次；区间条件于保存的预测，不包含重新训练和研究方案选择的不确定性。

## 数据怎样进入训练

[HemoPI2原论文](https://www.nature.com/articles/s42003-025-07615-w)采用HC50≤100μM作为高溶血活性、>100μM作为低活性分类标准。本轮保留来源标签；低活性不等于无毒。仅使用已缓存HemoPI2 cross_val的1540条来源训练记录；1428条满足标准20氨基酸、11–50残基。没有从本轮毒性结果选择辅助数据或阈值。

完整HemoPI2独立386序列、既有CAPTP测试序列、ToxiPep/ToxMamba独立集的序列及其辅助近亲连通群都从辅助训练中隔离。ToxiPep与ToxMamba独立集各958序列，存在重叠，不可当作1916个独立来源。测试文件仅用于身份隔离，未使用其标签/预测进行评分或选择。

1428候选中930条落在保留评估序列关联群，排除后498条。采用单位代价全局编辑距离≤最长序列长度20%的近亲边，并与旧主任务分组取传递闭包；它不是CD-HIT同一性。每折额外隔离对应评价群，并保守排除与现有评价样本引用相同PMID的辅助记录；最终每折辅助459–481条，两类各约200条。

原主任务训练样本也按新增联合群清除与评价群相连者，每折比旧划分多清除24–74条，三臂完全相同；每条原训练样本仍在自身评价折产生一次预测，没有改变或删除原始数据集。

来源可比性限制：1428候选759条能与Hemolytik按序列关联，但仅52条关联到含HC50文字的记录；这些关联也不能证明恰为来源CSV那次实验。每条原实验论文、化学形式及条件尚未逐项恢复，GHXTox原标签的完整测量来源也未知。已知引用排除不等于论文独立；**本轮是发表来源标签级探索，不是金标准、严格论文留出或独立泛化验证。** 旧OOF已参与研究。

保留整个HemoPI2独立集不等于使它自动成为GHXTox盲测：既有主训练与其中部分肽重叠这一历史问题仍在，原先69条待核外部候选也没有被评分。
协议data_quality_sensitivity中的保留集隔离指辅助训练来源及其组件；不表示原有主任务训练集与所有外部数据集天然无重叠。主任务仅按本轮外层评价组件清除近亲，不因外部来源同名而改写旧标签。此处是范围澄清，不修改拟合前协议/划分。

## 网络与公平对照

冻结原始ProtT5、1024维残基均值 → 128 → 64，两层ReLU共享小头 → 毒性头与辅助溶血头。三臂都包含相同参数；单任务仍计算辅助前向但辅助损失权重0，其余两臂权重固定0.2。辅助活性数值、论文、名称、注释和错误分组不作为新肽推理输入。

预先固定2种子×5折×3臂，共30次头部拟合；每次20epochs，AdamW学习率0.001，weight_decay0.0001；主batch256、辅助128。BCE正类权重仅从各训练任务计算。每折StandardScaler仅拟合主训练；各臂初始化、主batch顺序、辅助抽样、参数数目和优化步数一致。打乱标签保持类别数并在折内固定。无早停、调参、阈值选择或尝试其他辅助权重。

复用全部6387条主缓存及116条辅助向量，仅新编码382条辅助序列。编码冻结、用本地RTX4060约23.8秒；30个小头使用本地CPU2线程，训练脚本总计约57.4秒（含保存等开销，不含数据准备/核验）。未租服务器、未微调编码器/LoRA/Mamba、未训练3D分支。

旧主缓存与环境缓存68条共同序列最小余弦0.999998，另重编码3条检查与主缓存一致；配置与来源哈希保存。Torch/NumPy2兼容警告通过显式列表和LongTensor转换绕开，没有更换环境。首轮运行在第一次优化步前索引报错后修复；正式30模型完整成功。

## 判定与停止规则

拟合前已固定：概率均值MCC提升≥0.005、群bootstrap95%下限>0、两个种子不退化、AUPRC不下降超过0.002、真实辅助MCC高于打乱对照。实际仅“两个种子不退化”和“AUPRC未明显下降”满足，其余不满足。继续门槛失败。

不把这套辅助配置接入GHXTox，不围绕当前结果搜辅助权重/阈值/种子，不把数值微涨包装成生物机制创新。本结果只限制当前冻结序列均值+固定小头+来源标签方案，不能证明溶血监督在所有网络/数据上都无用，也没有直接检验三维辅助监督。

如以后继续，需要有独立理由的新假设与更充分数据，或者在冻结独立评估上验证新的分类收益；本轮不能成为继续堆模型的依据。当前更高优先级仍是已有独立评估、必要审稿消融和同协议基线比较，不立即再开启一个网络。
