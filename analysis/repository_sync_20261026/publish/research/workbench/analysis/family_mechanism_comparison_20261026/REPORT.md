# 整类机制与正确对照比较

> 后续核查已完成：Conantokin三条正确对照也都有Gla注释，Pr1/Pr2的Gla位置相同但预测一错一对。因此下文“优先补齐正确对照”已完成，不能继续把Gla有无当作获支持的致错解释。见[补齐结论](../conantokin_chemical_state_20261026/REPORT.md)。历史比较与缓存覆盖数按当时状态保留。

已比较全部148条“一维错、三维对”的训练样本：融合失败50条、成功98条。复用旧概率、旧空间特征、UniProt和文献缓存；未重算旧52对比较，未训练模型、调整权重或读取测试预测。

**目前支持的是分清不同问题，尚不支持添加一个通用“生物机制模块”。** 有化学状态遗漏的具体候选类别，也有分子片段与实验整体不一致的类别；空间电荷/疏水差异没有表现出跨类别的统一方向。

## 对照怎样找，以及实际能做到多严格

要求原标签相同，序列长度比例≥70%，整体比对相同残基比例≥40%；优先相同的UniProt明确家族，次选名称类别代理。名称类别不等于已确认同源家族。没有长度、Cys、电荷或疏水性的入组门槛。

|比较层次|实际结果|解释边界|
|---|---|---|
|50失败 vs 98成功，同折、不同序列组、家族/近序列|0对|不能直接将两组当成家族与序列背景一致的对照|
|50失败 vs 全部融合正确，同样严格要求|1对|不够做类级特征检验；预设32项检验全部标为配对不足|
|同折、同一既有序列组近亲补充|1个组内配对|两条失败近亲共享同一正确对照，只保留一对，不能数作两份独立证据|
|允许不同折，50失败 vs 98成功|1对|仅作描述，来自不同折模型|
|允许不同折，50失败 vs 全部融合正确|3对|其中2对跨折；不能作为独立验证|
|为研究整类背景，扩展全部327错题 vs 全部融合正确|27对|7对原阴性、20对原阳性，覆盖15个“类别×原标签”分层；21对跨折，只有3对两侧均有明确缓存家族，24对为名称类别代理|

后四项是看到严格对照覆盖不足后明确记录的探索性补充，不冒充预先指定验证。每项比较内不复用序列组；补充比较不做新的显著性检验。27对不是额外确认的机制病例，也不等同旧52对。

## 五类候选因素的结果

### 1. 二硫键与结构拓扑：可以测预测几何，暂不能公平比较真实键连

完整特征缓存覆盖失败组45/50，却仅覆盖成功组4/98。失败组18条有二硫键注释，成功组缓存中没有命中，**不能解释成成功组没有二硫键**；这是明显的资料覆盖不平衡。

已从已有ESMFold化学位点缓存读取Cys的SG坐标，补充近距离配对比例和序列连线交叉代理。≤2.5 Å是本轮选择的几何近邻界限，不是实验二硫键鉴定；连线交叉也不等于证明胱氨酸结或真实拓扑。很多短片段缺少足够Cys，根本不能恢复整个分子的二硫键框架。

较值得保留的整类线索是利钠肽：原阳性3对的Cys数量相同，错题的相对Cys间隔均更大；但SG近邻配对差只出现在其中1对，另外2对没有该差。正确对照2/3还带片段记录标记。因此，只能提出“环区范围/分子形式值得核实”，不能认定二硫键拓扑造成漏判。

### 2. 空间电荷与疏水分布：没有一个方向能解释各类错误

复用了局部正电荷集中、疏水接触、正电—疏水接触、同号电荷接触、两类残基的空间分离、疏水斑块和理想螺旋疏水矩等特征。它们描述的是现有预测结构或理想构象，并非膜结合态表面；净电荷也是KR-DE近似，未建模实验pH或修饰后的实际电荷。

例如PLA2原阳性4对中，疏水接触差和正电—疏水接触差均为2对升高、2对降低；不能归纳为“错题都缺某种疏水斑块”。Conantokin原阳性3对的理想螺旋疏水矩都更高，但其他空间指标方向不一致，而且下面的修饰状态尚未控制。利钠肽3对的同一疏水矩反而均更低。少量同向现象不能当作经验证规律。

逐类数值、每对差值和缺失数见[类级比较表](CLASS_COMPARISONS.md)及class_descriptive_summary.json。未把原阳性和原阴性混算。

### 3. 膜作用与靶点机制：需要分终点，不能用同一“毒性”解释所有类别

膜裂解、离子通道/受体作用、凝血/蛋白水解、抗微生物等功能提及已逐条保留原文、来源和否定词提醒。仅提到抗菌不能确认宿主毒性；提到受体或通道也不等于直接证明细胞死亡。功能由相似性推断、文献描述与直接实验证据分开保留。

Conantokin类的NMDA受体功能有部分条目为ECO:0000250相似性推断，另有条目ECO:0000269实验引用，不能整类升级为直接验证。利钠肽的受体/cGMP、血管和利尿效应与膜裂解也不是相同终点。

已有原始文献缓存支持Ectatomin的双链整体效应、H1/H2的相关生物效应，但前者不能转给孤立亚基，后者的修饰与具体条件仍有冲突。综述PMID26805882已另标为综述，不能冒充逐条原始实验；其余新类别未缓存到原始摘要的，明确标为缺失，没有借家族整体效果补标签。

### 4. 分子完整性：在整类中反复出现，但不是区分所有对错的充分条件

PLA2类找到6对同原标签、相近序列的候选对照（原阳性4对，原阴性2对）。两边12个输入均命中片段记录标记。L-amino-acid oxidase、金属蛋白酶类的候选对照也常在两边出现片段标记。

这支持把“输入短片段能否承接完整蛋白的实验效应”作为类级审查问题；但正确和错误两边都有该标记，所以不能简化成“所有错误都是片段导致”，也不能将模型判对当作已证明片段确有同样活性。any_fragment_match表示至少一个精确身份匹配有片段标记，不等于已独立核实每条天然完整分子。

### 5. 化学修饰：Conantokin比继续只盯H1/H2更适合作为整类核查候选

Conantokin原阳性3对中，3条错题（195、57、66）均有4-carboxyglutamate注释，且对应位置在现有FASTA中均编码为普通E，已逐位核验。3条正确对照（854、359、218）的完整修饰特征未在本地缓存中，不能当作未修饰组。

因此，目前成立的是“输入未区分已注释的化学状态”，还不成立“遗漏该修饰造成错误”。修饰可能改变电荷和构象是需要验证的候选解释，不能用当前KR-DE近似或未修饰结构证明它。正确对照的修饰状态是这一类最明确的资料缺口；先补齐它，才值得做标准E与修饰感知表示的公平小试验。

H1/H2仍保留化学形式冲突状态；不把两条案例作为通用修饰机制的证据。

## 另一个必须排除的混淆：分支阈值不同

一维、三维、融合的既有阈值分别约0.3921、0.6778、0.4702。50条“三维对、融合错”中有7条，即使只用三维概率、按融合阈值判定，也仍会错；这7条均为原阴性。它们的“三维对”部分依赖三维自身更高的阈值，不能直接解释为融合丢掉了正确生物学知识。

其余43条按固定公式可见序列分支的权重把融合推到错误一侧，但这仅说明分数行为，不能证明真实机制。没有尝试选择新阈值或新权重。全部148条的公式和判定均已核验。

## 实际优先顺序

1. **优先补齐Conantokin整类正确对照的修饰信息**，再做化学状态是否提供普通序列之外信息的最小计算对照。该方向有具体输入缺口；当前只有3对候选，仍需更完整的类别证据，不能马上宣称泛化。
2. **并行保留PLA2等片段类别为对象边界分析**，区分天然短肽与蛋白片段；不重标，不拿完整酶效应自动给短片段加权。
3. **二硫键/利钠肽环区候选排后**：先补足正确对照的真实键连、完整分子和终点；目前几何代理与少量配对不足以支持新拓扑网络。
4. **暂不增加通用空间电荷/疏水模块或全量MD**：本轮没有得到跨类别一致的新规律。融合的阈值/权重问题应与机制研究分开验证。

这是计算研究，未要求开展生物实验。下一步也先解决具体证据和输入状态的可比性，不租服务器或重训整个GHXTox。
