# Na1b同机制样本扩展与比较（2026-10-25）

本轮从训练集继续扩展到9条代表样本。6条可关联具体的直接哺乳动物细胞/红细胞实验，另3条仅作背景。新增确认的漏判包括Lycotoxin I和LyeTx I；找到Oxyopinin-2a作为有直接实验的正确样本。不过，各论文的实验条件不同，目前没有形成严格同条件配对，因此还不能判断哪个新特征能稳定纠错。

最值得优先处理的发现：原来的“有毒/无毒”标签可能混合了不同物种、浓度和终点。需要给这些样本补上实验背景，再研究模型盲点。

## 三、现有特征能解释吗

逐条数值见同目录 `feature_comparison.md`。先看几个容易误判的现象：

- **高pLDDT没能保证判对。** Na1b、Nc2a、Lycotoxin I、LyeTx I的平均pLDDT约0.885–0.931，仍被融合漏判。它表示结构预测的置信度，不能当作膜环境活性构象的实验验证。
- **简单电荷、疏水性还没有给出稳定分界。** 这些直接终点漏判样本长度都是25残基，唯一直接终点正确阳性Oxyopinin-2a为37残基，电荷也更高。长度、家族、化学状态和实验条件相互混杂，不能据此设计“短肽加权”规则。
- **已有疏水斑块特征无法区分这批代表样本。** 上述4条漏判及Oxyopinin-2a的`hydrophobic_patch_fraction`均为1。不能把同一个已有指标重新包装成新信息。
- **3D分支值得诊断，但不是每次都会把融合拖错。** Lycotoxin I、LyeTx I是一维对、三维错、融合错；Oxyopinin-2a也有一维对、三维错，但融合保住了正确判断。只依据一维/三维分歧加权还不够。

本轮直接终点核心6条中，原标签阳性5条（4条融合FN、1条TP），另1条是Nc1a原标签阴性。这是目的性选择的探索小样本，**不能把4/5写成膜活性肽的全局漏判率**。没有做显著性检验或训练分类器，因为只有1条跨论文正确阳性，无法排除家族与实验混杂。当前可确认的是“值得继续检查的病例”，尚未确认“可泛化的共同致错规律”。

## 四、如何借鉴生物学做下一步

优先级1：先按实际实验补充旁表：测谁（人细胞/兔红细胞/昆虫）、测什么（死亡/溶血/膜泄漏）、什么剂量/时间、哪种末端状态。保留原主数据集。只有背景接近，比较判对与判错才有解释力。

优先级2：围绕“接触不同膜后，活性是否改变”收集同一条肽的成对实验。原文的膜物种、脂质组成与环境变化提供了生物学动机，但现在的数据还不足以给所有样本赋环境标签。先整理真实测量，不从序列猜出环境标签后当真值训练。

优先级3：在足够多、跨家族且背景可比的可靠样本上验证，现有静态结构能否解释作用差异。若环境或化学状态确实提供独立信息，再设计最小模型试验；比较普通难例加权与生物学改动，避免只把噪声样本放大。

目前不建议直接扩大争议样本权重。这一轮发现说明，部分“模型判对”只是符合原标签，“模型判错”也可能涉及不同终点下的标签含义，必须先区分。

## 五、文件与可复查范围

- `endpoint_comparison.json`：9条训练身份、原标签、冻结1D/3D/融合结果、实验对象、条件、证据位置和未知项。
- `feature_comparison.md`：9条已有特征并列表；疏水矩为理想螺旋的序列代理量，不是实测膜上构象。
- `same_paper_matches.json`：Na1b同篇5条序列的训练匹配，含未匹配记录。
- `discovery_candidates.json`：宽关键词发现的243条accession记录，包含阴性描述及片段，**不是243条确认的膜毒性肽**。直接证据提示还需逐终点审核，不能把FUNCTION中一个ECO实验来源扩展到整段全部功能。
- `sources/`：UniProt逐条JSON、原研究搜索记录及其他Oxyopinin序列的训练匹配。出版商直连部分受限，使用原研究索引全文；不采用商品网站的序列与活性断言。LyeTx I的PDF文字已核对Fig.3，截图接口失败，未完成图像复核。
- `build_comparison.py`：可重建旁表与核对结果；只读取冻结训练OOF，不读取测试预测，不重新训练。
- `verification.json`：6387条训练输入、9条短名单、6条核心/3条背景、身份精确对应、输入SHA256前后一致。

这不是独立外部性能验证。既有OOF存在历史校准/选择独立性限制；本轮只做病例发现和生物学假设形成。未改权重、标签、训练/测试数据或模型，没有开服务器或使用收费算力。
