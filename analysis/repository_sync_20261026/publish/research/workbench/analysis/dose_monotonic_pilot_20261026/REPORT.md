# 剂量—反应单调约束：首轮计算结果

日期：2026-10-26，仅主Agent执行。**单调约束消除了预测中的反向波动，但没有提高溶血比例的数值准确性，本轮不支持据此扩大为复杂神经网络。** 这是特定数据、表征和小模型的可行性结果，不是证明剂量或其他模型没有价值。

## 做了什么

复用已有面板，不重解析数据库或重跑旧70次环境回归。原库不变，只在派生视图中排除已确认的非直接观测：严格范围内2条SI错列和1条HC50衍生记录。

|口径|至少3剂量的候选面板|测量点|序列|来源PMID标识|
|---|---:|---:|---:|---:|
|主口径：已确认非直接点隔离|284|1305|269|90|
|敏感性：另隔离所有恰好50%记录|253|1208|238|84|

两种口径均保留全零、全百、小变化及轻微非单调面板，没有按结果是否好看选曲线。敏感性口径按观测值排除记录，可能排除真实50%测量，不能称更干净的金标准。

固定为整篇PMID留出的五折，并清除训练侧与测试侧相同的既有编辑距离群；同一肽不同剂量不会被随机拆到两侧。敏感性口径沿用主口径的论文分折映射。pH等未知状态照实保留；相同未知字段并不证明实验条件一致。

输入为已有定义的氨基酸/二肽组成、6项序列及末端特征、红细胞类别、log剂量；没有使用肽名、论文ID、HC50、SI、SMILES、测试标签或旧模型预测作输入。未重新提取ProtT5或生成结构。

使用相同超参数的HistGradientBoostingRegressor：普通模型与只对log剂量施加非递减约束的模型。每个训练面板总权重相同，固定150轮，无早停或调参。约束功能属于已有算法功能，不当作方法创新。[官方API](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html)

两口径×五折×两模型，共20次本机CPU拟合。每折训练点769–1024；未使用GPU或租服务器，没有改动GHXTox。运行脚本记录约14秒，不包含资料准备和独立核验时间。

## 结果：曲线方向得到约束，平均误差未改善

主指标先计算每组面板的平均绝对误差，再对面板等权平均，单位为溶血百分比的百分点，越低越好。它不是毒性分类准确率，也不是HC50误差。

|模型|主口径平均误差|敏感性口径平均误差|
|---|---:|---:|
|仅预测训练侧加权中位数|26.60|25.90|
|普通剂量模型|24.24|25.08|
|单调剂量模型|24.80|25.52|

“普通模型误差减单调模型误差”为正才表示改善：

|口径|误差改善点估计|序列群配对bootstrap 95%区间|改善折数|
|---|---:|---|---:|
|主口径|−0.56|[−1.20, +0.07]|1/5|
|敏感性|−0.44|[−1.03, +0.15]|1/5|

来源PMID重采样区间分别约[−1.10,+0.18]和[−1.18,+0.40]，也跨零。没有确认改善，也不宣称已证明显著变差。区间只基于固定折外预测，不覆盖所有重新训练和原实验不确定性。

主口径普通模型有39/284组、共50个相邻预测步出现下降；敏感性为47/253组、60步。单调模型两口径均为0，在每组64个log剂量网格上也均无下降。**这由算法约束保证，不能单独当作生物机制验证；常数预测同样不会下降。**

相邻剂量响应增量误差由10.72降至10.57、由9.29降至9.05，说明局部变化的一项描述有所改善，但不足以抵消绝对水平误差。没有据此改换主指标或宣布晋级。

## 误差主要在哪里

结果出来后另做了不训练的描述性分解：面板均方误差可精确分为“所测窗口内平均响应水平偏差的平方”与“中心化后的形状误差”。主口径两个模型约80.5%和81.7%的平方误差来自前一项；敏感性约83.2%和83.7%。

通俗地说：在这批数据上，模型往往把一组剂量点整体预测偏高或偏低；只规定“不许随剂量下降”没有解决主要数值误差。这不是“80%的样本有某种机制”，也不能据此判断偏差由序列表示还是未报告条件造成。

中心化使用真实测试面板的均值，仅用于事后误差诊断，未作为输入、校准或修正预测，也不是新增可部署性能。

## 下一步决定

预先冻结的继续条件要求：主口径改善区间下界>0、至少4/5折改善、敏感性同向、增量误差不恶化。本轮只满足最后一项，`decision.json`判定不扩大、不围绕这些结果继续调参。

因此：

1. 暂不把普通单调头写进GHXTox，或以它作为新网络创新主张。
2. 保留“剂量条件下的溶血比例预测”作为独立任务。这次实际测试的是未见论文、未见近亲序列的跨来源泛化；不等同于已测肽的新剂量插值，也不等同于特定受控实验下的完整曲线识别。
3. 若继续，应先核实直接多剂量表及条件元数据，固定少量跨来源可比面板，检查整组水平偏差；不立即更换复杂编码器、继续调小头或拟合HC50。现有曲线不足以支撑把未覆盖50%区间的数据强行换成HC50。

## 交付与核验

- protocol.json、freeze_manifest.json：新模型预测前已冻结的规则与输入哈希。
- prepared_data.json、两套point_manifest.csv、folds.json、split_summary.csv：逐点来源与整论文/近亲排除。
- oof_predictions.csv、panel_losses.csv、fold_metrics.csv：所有折外预测和组等权误差。
- grid_monotonicity.csv、fold_models/：可复核网格与20个实验模型，未部署。
- paired_comparisons.json、decision.json：成组区间与原定停止条件。
- residual_decomposition.json：仅事后描述的误差分解。
- verification.json：独立复算全部面板MAE/增量、重载所有模型复现预测（最大差0）、确认仅剂量约束不同、无论文/序列群泄漏、64点网格无违背、原输入哈希未变。

这批数据此前已经用于探索，不能包装成新盲测。来源PMID并非全部已确认独立原始实验，时间/温度/密度等缺失；主口径仍可能存在未识别的终点衍生记录。结论限于本轮候选面板与固定模型。
