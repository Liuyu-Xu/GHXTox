# LoRA修复与三组对照结果

完成三组真实 ProtT5 + BiMamba 开发训练；低Cys和家族加权未启用。每组独立使用同一训练/验证划分与相同初始分类头、顺序。LoRA两组每轮144个B矩阵更新，所有记录的优化步骤均成功。

|方案|验证BCE↓|选中轮数/总轮数|一维MCC↑|一维AUPRC↑|一维错题|条件融合MCC↑|条件融合错题|
|---|---:|---:|---:|---:|---:|---:|---:|

按验证BCE在两档LoRA中选中1e-5；它相对无LoRA，一维纠正14条、添错20条，MCC差−0.0120，配对序列组bootstrap 95%区间约[−0.0350, 0.0101]。条件融合纠正8条、添错12条，MCC差−0.0076，区间约[−0.0247, 0.0106]。区间跨零，单次结果不支持确定优劣。

3e-5在留出折一维MCC与无LoRA接近、融合错题少1条，但它未被训练内验证选中；不能看过这些结果后改用它并将此结果当独立验证。

本轮外层留出1271条；同一折此前在A/B研究已看过，因此只是探索性比较。每个预测分别用独立校准角色拟合Platt；融合为单一一维模型加固定历史3D OOF，不是论文三种子完整模型或全流程严格独立评价。仅一折、一个种子，bootstrap不包含训练随机性或候选选择带来的不确定性。未使用Test1/Test2。

代码修复与梯度检查确认可用；本次尚未证明启用LoRA带来稳定收益，也不能证明LoRA永久无效。保留旧模型，后续要以训练内选择方案、其他折及种子重复比较，再决定是否删除。
