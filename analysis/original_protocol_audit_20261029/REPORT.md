# 原GHXTox协议核对与最终对照方案

## 对照对象与证据

本报告的“原版”是本地旧公开默认配置 configs/default_multidimensional_fusion.json 对应的历史完整模型，不等同 2026-10-27 无额外Transformer的新结构交接版。以 src/ghxtox/multidimensional_default.py、src/ghxtox/lora_mamba_1d.py、configs/lora_mamba_1d_autodl.json、runs/lora_mamba_full 和已保存原测试预测为依据。代码存在本地修改，应记录原始来源commit和审计版本，不能声称这些文件全部与最新GitHub逐行一致。历史测试Test2包含于Test1，且曾参与开发。

## 两层对照目标

1. 历史锚点：不改旧checkpoint及原公共推理，复核原Test1/Test2预测和指标，历史模型代表真实既有成果。输出作为参考，不能仅用旧模型与新训练模型的差异归因算法。保留完全相同的已保存测试3D预测，确保无样本变化。
2. 公平算法对照：基线和候选从同ProtT5初始化、同architecture、同fold/完整数据、同seed42/123/2025、batch/优化器/训练轮数/正类权重及可预见的数据采样规则；在历史分组五折生成三种子OOF及三个全训练checkpoint。原流程按15轮固定为可重复冻结协议，不能声称100%复刻实际历史命令。决策以审计后可再生基线与候选的配对差为主，旧原checkpoint作历史锚点；生成过程、运行时版本、原LoRA0/实际激活全部记录。若基线无法接近旧原模型先查清，而非继续宣称改进。

## 预先确定的最小实验

A 基线：原训练的分类损失、普通shuffle，不改原标签和训练集。保持冻结ProtT5、双向Mamba架构；参照已检查三份零LoRA权重可采用无LoRA作为实际行为复现实验，但 must 同时核对其dropout、随机初始化与训练轨迹，不能因为推理等价就声称从头重训相同。若严格复现运行原配置LoRA模块且确认B零，单独做明确代码版本的数值检查，不能静默开启LoRA微调。

B 候选：先只加普通SupCon损失（固定lambda、温度、batch构对和疑点处理）+原有分类损失；保留相同训练样本、普通shuffle、正类权重及训练预算。疑点标记仍参与BCE，不参与SupCon，这使差异同时包含对比项的样本参与规则，需在报告讲清。必须每批正负标签至少有可用对，空对损失为零并记录有效锚点。

C 扩展（按资源决定）：在B基础上加入低/高Cys组内对比；如果要启用分层batch采样，另加D=同分层采样但无SupCon以隔离采样效应，保持相同样本及更新次数；不得把分层和SupCon一起加给候选而声称效果全由SupCon贡献。疑点样本仅普通训练、不额外采样是另一个单独随机采样策略，公平比较应有同抽样预算对照；训练全删疑点是另一个实验，不在第一轮混入。

## 训练和校准

每组3 seeds×5折生成OOF+3全训练checkpoint，共18模型/组（若共享ProtT5加载及3D不变可减IO，不可把旧一维OOF代用为新候选）。按各自组的三个OOF原概率先均值，再分别用同一种C=1e6 Platt拟合；完整模型的3个seed原概率先均值再应用该组Platt；同一旧3D测试分数、融合0.72/0.28和阈值0.47022256531284556以保留历史比较，不按测试指标微调。若要考察阈值泛化，另外用训练内预设公平规则，双方同样处理，不选择最佳测试阈值。全OOF上拟合校准再评价同OOF有信息重用，OOF仅开发诊断；稳健泛化另用嵌套交叉拟合/真正未观察数据，不能称无泄漏。

原测试1/2：全部组预先冻结，同一次输出完整MCC、AUPRC、灵敏度/特异性、FN/FP、四个Cys原标签组和纠正/新增，配对bootstrap；Test2子集、都已开发使用，历史对比不是两个独立盲测。模型和网络不能使用真实标签、疑点标记作为预测输入。数据来源重叠、结果选择和有限测试正样本应列局限。

## 决策点和经费

先做原完整推理重建、最小训练兼容小批次及对齐测试，核查自动校准和原数据划分、种子数、权重更新与目标；记录原代码版本哈希和训练/验证/校准行为。各组预备实际初始state、随机性、数据覆盖和日志；确定折外隔离，再估算GPU时间与存储。历史原始三seed旧权重的初始化、训练时实际epoch及当时环境尚不完全可得；不同环境不会自动复现旧原结果。同一工程的新基线/新候选可以公平匹配而无须承诺重现旧指标。

第二种子实验目前仍是现有五折预实验，已运行资料应保留用于前期证据，不作为该18模型/组完整方案。服务器费用未经实测，不给出确定数值；先测一小批/一折成本，给出真实测量再规模化。
