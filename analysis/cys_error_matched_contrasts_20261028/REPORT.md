# Cys 极端样本：同标签错误与正确对照

## 方法及已有工作

复用原完整 GHXTox 三种子序列分支和结构分支融合的 6387 条历史训练 OOF；分别在低 Cys（0–1）原有毒、高 Cys（≥6）原无毒两组内，比较错误和正确样本的特征中位数，并看五折内差异方向。原标签只用于事后分析，实际预测时不能用标签或是否错误作为输入。没有训练分类器或使用 Test1/Test2。

同家族更严格的分析已经完成（见 ../cys_extreme_within_family_20261028/REPORT.md）：低 Cys 历史模型仅有 8 个候选对，高 Cys 为 0 个；这里是整组比较，不是同家族匹配，家族、序列相似性及来源可能混杂。以下均为探索性关联，未做多重检验，不能证明机制或跨数据集稳定。

## 比较结果

| 特征 | 低 Cys 有毒：错误/正确中位数 | 高 Cys 无毒：错误/正确中位数 | 说明 |
|---|---:|---:|---|
| 样本数 | 140 / 122 | 50 / 190 | 相对原标签 |
| 平均疏水性代理 | −0.232 / −0.458 | −0.362 / −0.020 | 低 Cys 方向 4/5 折一致，高 Cys 4/5 折相反；差异可能受家族影响 |
| 预测结构平均 pLDDT | 0.719 / 0.765 | 0.712 / 0.825 | 两组错误中位数更低，但五折方向并不一致；不是结构真实或毒性证据 |
| 低 pLDDT 残基比例 | 0 / 0 | 0.094 / 0 | 高 Cys 五折均呈错例偏高，个别折仅 3–4 个错例 |
| Cα 回转半径 | 11.14 / 10.71 | 9.01 / 7.98 | 高 Cys 五折均呈错例偏大；受长度、家族和预测结构影响，未校正 |
| 两分支概率差绝对值 | 0.113 / 0.145 | 0.148 / 0.023 | 高 Cys 四折方向一致、一折接近无差异；并非证明融合可自动纠错 |
| 已有标签疑点标记数 | 62/140 / 41/122 | 18/50 / 38/190 | 标记包括片段或跨源冲突，不等于确认标签错误；未标记不等于可靠 |

方向按该折内连续指标区分错误/正确的 AUC 是否高于 0.5 计算；接近 0.5 可能只是细小差异。高 Cys 的五折错例数量分别为 3、16、10、4、17，方向一致不等于统计显著，也没有控制长度及家族。

低 Cys 错误的 1D/3D 概率中位数分别为 0.081/0.006，正确样本为 0.889/0.962；高 Cys 错误分别为 0.902/0.996，正确样本为 0.022/约 0。两分支常一起表现为相同方向。但这里限定了已知标签，再按融合模型是否错误分组，概率差异部分来自分组定义，不能据此说训练时能识别真实错误或知道哪个分支对。

已有 max_otherfold_kmer_cosine 在两组中错误样本较低，但它是对其他折整体计算的相似度，并非严格仅对当前训练折的参考库计算；属于描述性线索，不可直接用于无泄漏预测。预测结构与物理化学特征均是代理，不是实验膜结合状态，不能认定因果。

## 建议下一步

在当前训练数据里先做一个严格按外折重建参考库的轻量错误风险探针：只用推理时能取得的分支预测、长度、pLDDT、残基组成等，不能输入真实标签、错误标志、标签证据或事后家族结论；开发折内部选特征并对比仅使用原概率的简单基线。以组为单位划分，分别报告召回、误报警、纠正/新增错误和整体 MCC。此探针只能告诉我们哪里不确定，不会自动知道真实标签；若要修正预测，还要有额外纠错信息并另做嵌套验证。由于历史上游 OOF 非完整嵌套，最终需要完整嵌套重训或真正未用过的外部数据。

全部特征、各折数值、覆盖量在 results.json；analyze.py 可复现。统计未使用测试集，未更改标签。
