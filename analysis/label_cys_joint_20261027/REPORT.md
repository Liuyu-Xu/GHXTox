# 标签疑点与Cys短板：联合诊断

2026-10-27。复用既有6387条索引、标签triage、旧Test报告和178条独立配对。不重新计算Test1/Test2、不新增文献核查、不改标签/数据集/阈值/权重，不训练神经网络。本轮8个GLM只描述历史错误与因素的关联，不是新毒性分类器或学习权重。

## 决策

两类短板需要分开处理：**低Cys漏判不能由现有统一疑点标记解释，应优先继续检验模型依赖的背景规律；富Cys误报与疑点标记同时集中，不能整体提高学习权重。**在没有完整原标签证据链前，暂不训练“可靠性权重”，也不把未标记样本全部称为可靠。

## 1. 恢复旧定义，纠正对“显著”的概括

历史Test1：有标记错误率33/344=9.59%，未标记26/782=3.32%，Fisher p=3.39e-5，双主比较Holm p=6.78e-5。历史Test2：15/211=7.11%与16/371=4.31%，总体Fisher p=.179，未达到通常显著阈值。按原标签分层CMH分别提示关联，但Test2是Test1子集，不是两个独立重复；旧分析未控制家族。

本轮只引用已有统计，不拿Test1/Test2确定权重、改阈值或验证新方法。完整定义和限制沿用 ../test_ambiguity_association_20261025/REPORT.md。

### 统一主标记

- 精确序列匹配到保留UniProt快照中带Fragment的参考条目；或
- 相同规范序列在保留来源出现相反广义/操作性二分类标签。溶血与广义毒性不同端点未被直接混作冲突。

两项并集仅计一次，全6387以同一规则覆盖，不使用预测对错。片段提示实验完整分子与输入可能不一致，冲突可能来自不同终点/条件；均不是确认错误标签。身份未恢复924条另列，不自动加入主标记。

## 4. 可靠性分级能做到哪一步

|证据状态|当前记录数|可否直接作为学习权重|
|---|---:|---|
|完整原二分类终点、分子/化学身份和证据链均核实|0条满足本轮严格标准|不能估计这类错误率；0不代表所有标签都不可靠|
|有统一主标记或具体人工对象/形式/终点疑点|1884|只作为核查侧表，不能直接统一降权|
|未完成原标签证据链核查、暂无上述记录|4503|资料不足/未逐条核对，不能自动提高可信度|

主统计用1875/4512而不是1884/4503，因为额外9条来自偏向错题的人工细查；把它们直接加入主关联会造成“错题查得多，疑点也多”的偏差。保留36条人工细查及21条具体疑点侧表，但不据此估计全体疑点发生率。

四条已有直接效应候选（peptide_94、249、463、1434）支持特定终点效应，但原广义标签判定链仍未知；存在弱效应、化学形式与阈值问题，不能升级成严格原标签金标准。其中3条落入低Cys共同漏判，正说明不能把真实效应候选全部视为噪声。

## 5. 条件关联：完成了什么，尚未完成什么

按原标签分别拟合历史错误的探索性GLM：难Cys组（正类低Cys、负类富Cys），调整片段、来源标签冲突（仅有变异时）、长度样条、原留出折和身份未恢复。按原序列聚类group_id计算cluster sandwich区间。不是按模型置信度给标签评级，也不是用于推理的分类网络。

OR是错误优势比，不是错误率倍数。协变量调整后的OR改变也受非可折叠性影响，不能把大小变化解释为某个因素贡献了多少。当前仍存在条件关联，但没有证明模型因果依赖Cys，更没有证明Cys本身造成错误或去偏训练一定提高。

**来源与家族无法据当前记录完成充分控制：**

- 总数据沿CAPTP等来源链已知，但6387条逐样本原始数据库/原二分类实验终点字段均未恢复；当前UniProt匹配不是原标签来源凭证。跨来源冲突标记不能代替真实来源变量。
- 已有完整缓存的curated family只覆盖205条，名称代理覆盖559条，且详细缓存偏向旧错题。把其余统一填unknown再回归不能称为控制了家族。
- 原正类同序列聚类组内同时含高低Cys仅3组8条；原负类2组17条。它们是序列聚类组，不是完整生物家族。
- 真正curated family中，原正类没有同时具备两种Cys层的缓存家族；原负类只有3个家族共7条，旧错误在这些小组内也没有变异。当前没有足够共同背景作可靠Cys效应检验。
- 名称代理虽有更多跨Cys组，但范围宽且缓存选择偏差明显，只列清单，不冒充充分家族调整结果。

因此本轮完成“疑点/长度/折等条件下关联仍在”的初步验证，**尚未完成排除家族/来源后的捷径因果验证**。历史OOF与研究假设已多次被观察，结果不是新盲测。

## 6. 下一步实施顺序

1. **优先低Cys主短板的背景验证。**从全421条及原正类背景出发，复用90条无主标记共同漏判与110条同类正确比较池作为诊断子面板；保留有标记者作敏感性背景。先检查同家族/近序列条件是否具备高低Cys及错误状态的共同支持，按整类补齐对称信息，避免只查错题。
2. **富Cys原负类保持证据与模型双轨。**29条有标记共误与35条无标记共误分别保留，连同对应正确背景；不能将29条认定错标，也不能把35条认定可靠。尤其不能把“另一来源有毒”直接改成统一正标签。
3. **暂不计算可靠性数值权重。**当前严格原标签可靠层为空，元数据覆盖偏差明显。先固定证据定义和可用覆盖；资料不足保留默认处理，不以缺文献、低置信度或预测错误自动降权。
4. 若后续得到充分背景支持，再做原训练/仅困难群体处理/仅可靠性处理/二者结合的最小对照，最终看完整GHXTox的纠错与添错、MCC/AUPRC以及所有四类表现。权重学习和阈值选择只在外层训练部分内部，不能用当前全OOF错题身份作为未来评价的答案路由。

本轮不因资料有限停留在逐条个案，也不启动无法解释的可靠性感知网络。先解决“哪些分层可公平比较”这一具体缺口，才有依据决定去偏训练。
