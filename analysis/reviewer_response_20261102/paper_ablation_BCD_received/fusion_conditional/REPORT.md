# C组第5折审查和条件性一维三维融合

## C组第5折审查

第5折（fold4）中，无门控三维主干的验证集 MCC 0.7910，校准集 0.721，留出折 0.6735；选择的权重为第1轮，之后连续8轮没有超越而早停。该折同样本的 A 组三维主干 MCC 约0.7949，B为0.7886，D为0.7818。C留出折主干误报125、漏判62；加入化学位点后误报129、漏判60，MCC为0.6723。因此大部分异常在化学位点训练之前已经存在。该现象与去掉门控后该折训练或泛化不稳定相容，但单种子无法识别原因，更不能仅凭第1轮选中认定训练错误、欠拟合或pLDDT是唯一原因。

## 条件性融合

输入为历史三种子一维 OOF 加原历史全量 OOF Platt，和每组每折三维单独用内层校准集拟合的单调 Platt；然后固定1D/3D=0.72/0.28与论文阈值0.4702225653。所有组使用同一份一维分数、同一阈值。三维 Platt 用 scipy L-BFGS 拟合与项目同样的正斜率交叉熵目标，不应表述为历史原始权重及其原始校准的复现。

B、C、D 与A的MCC差值区间均跨0。A和D的MCC和错误数相同但逐样本预测不相同：D纠正31条、同时新增31条错误。C组融合后第5折MCC 0.8584，A为0.8606；一维占72%，故融合后明显缓和三维问题，但不能证明一维逐条纠正的机制或泛化效果。

与同组主干相比，A加化学位点的融合MCC变化 -0.00045，95% CI [-0.00251, 0.00151]，纠正3、新错4；该区间条件于已训练模型和选择规则，不能判定总体无作用。C 4折、D 2折是预设零化学残差回退；A fold4是训练后补做回退。

限制：一维 Platt 使用全体OOF标签拟合，包含每个留出样本标签；原始一维各折训练划分也不是本次的同一套嵌套内层划分。这里是带标签暴露的探索性复用，不能作为严格无泄漏完整模型OOF、独立外部测试、论文最终验证或模型是否优于历史部署模型的证据。2000次原分组配对bootstrap、无标签分层，只反映固定预测的抽样误差，不覆盖训练随机性。模型配置、校准训练、数据划分和回退规则还需统一并复核后，再形成审稿正式对照。各折校准系数及完整统计见 summary.json，逐样本见 predictions.csv。
