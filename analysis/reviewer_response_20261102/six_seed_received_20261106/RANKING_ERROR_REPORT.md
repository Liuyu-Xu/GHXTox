## 下一步判断

现有五折对照尚未显示稳定的 MCC、AUROC 或 AUPRC 融合增量。Test1/Test2曾参与开发且后者是前者的子集；在未确定六种子全训练重拟合和校准协议的情况下，不建议把五折模型直接平均或利用测试集挑选阈值来制造补充结果。旧部署的3个一维权重与本轮15个嵌套模型训练谱系不完全一致；若之后补做部署形式的回顾性测试，应预先锁定全训练种子、训练预算、校准来源和各模型对照，并标为非盲测。更优先准备实验终点清楚、与已用数据隔离的外部评价；仅凭无显著差异不能宣称结构无用。
