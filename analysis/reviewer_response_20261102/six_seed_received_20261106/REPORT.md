# 六种子一维与三种子一维＋三维：训练内对照

## 文件和训练检查

下载包 `six_seed_new_results.tar.gz` SHA256：`d73a71282b25e1459bf48d519a5593ff3cc876ccaaab16f2146544d84b233c42`。调度日志显示三个种子314、2718、2026各五折共15项全部 exit 0、SCHEDULE_COMPLETED。逐项检查15轮日志、权重和两套预测文件的 SHA256，均通过；每项约13.05–13.40分钟，单进程最高GPU reserved约3.81 GiB。并行时总显存并不等于单进程数值。

三种新种子与既有种子42、123、2025的训练划分、模型代码、训练配置和 ProtT5 权重及tokenizer哈希一致。新训练器只扩充种子可选范围，不能把不同随机种子下的训练结果当成同一模型。每折训练使用 train 角色，calibration 和 test 不用于梯度。原始新种子文件保存在 six_seed_new_results；完整结果 comparison/summary.json、逐样本 comparison/predictions.csv。

## 对照及结果

五折共6387条训练数据的外层留出预测。融合组使用前三个一维种子和同一划分下重训的一个无化学位点三维 backbone；六种子组为六个一维预测平均。每个外折把 calibration 按序列组拆成拟合校准和选择参数两半；Platt 拟合、融合权重和阈值选择均不使用该外折。固定方案使用0.72/0.28及0.4702225653，但两个方案均采用本折训练内重新拟合的校准，不等于历史部署预测。调参方案在选择集选权重/阈值；六种子组只选阈值。区间为2000次按序列组配对bootstrap，仅反映固定预测的样本重采样变动。

六种子减融合的 MCC 差：固定方案 **+0.00009，95%区间 [-0.00699, 0.00672]**；内层选参方案 **+0.01001，区间 [-0.00031, 0.01975]**。区间都包含0；不支持断言任一方案显著更好。固定方案中，六种子独对44条、融合独对43条；内层选参分别99和74条，包含不同阈值选择的影响。

固定方案的融合 AUROC/AUPRC 点估计比六种子略高（+0.00113/+0.00044），本轮没有计算这两项差异的区间，不能断言有稳定排序收益。调参方案融合各折权重0.72、0.72、0.85、0.72、1.0：第5折权重1.0即未使用三维；融合阈值0.42–0.78，六种子阈值0.36–0.74，提示内层选参不稳定。训练内比较不应选择较好结果后再当盲评。

## 解释边界

本次不支持说加入三维比六种子纯一维带来稳定的MCC增量；也不证明三维信息没有价值。对照使用一个重训三维专家，而不是当前由 full2795 原权重移除化学位点的部署模型；三个一维＋一个三维与六个一维的模型数量和计算成本不严格相等。三维完整上游谱系仍需结合历史审计解释；研究数据已被反复探索，不能称独立外部盲测。外层没有用于本次参数选择，但 bootstrap 不包括重新训练、划分或模型选择的不确定性。
