# 低Cys漏判、高Cys误报：候选方法与研究路线

## 用户提出并需保留的方向
主模型学习总体规律；针对低Cys原正类漏判、高Cys原负类误报探索受限的补充学习，最后与主模型融合或受限修正。训练时可按真实原标签定义群体；推理时绝不能使用真实标签，Cys数量可由输入序列计算。先证明每种补充信息独立有效，再考虑门控/融合/蒸馏。提出该方案尚未验证。

## 已有证据
- 旧三份最终一维权重LoRA B为零，仅在已检查权重确定；默认已移除。最近新训练无LoRA单种子不能与历史完整三种子集成混称。
- 低Cys正类统一1.5加权：其余四折单种子条件融合低Cys正类FN 172/328→154/328，但总错误320→343，MCC 0.8444→0.8337，AUPRC下降。涉及大量标签疑点，不能推断Cys因果或代表完整三种子。
- MCD/NDBP额外加权首折4个目标仍全部漏判，C相对B整体多错22条；目标少、非盲，不能推广结论。
- 普通监督对比首折条件融合MCC 0.8308→0.8455、错误88→80，但低Cys正类FN 38/93→42/93；区间跨零。排除疑点对比项组整体0.8365，不能判标签可靠性。五折尚未跑。
- 原错误地图中旧/新共同漏判低Cys原正151条、共同误报高Cys原负64条；标记比例分别61/151及29/64。标记是片段或跨源冲突风险，不等于错误；未标记非可靠证明。
- 严格同完整家族、异标签、相近Cys及长度并要求编辑相似≥0.5且双方无旧疑点，每折1–4对、高Cys0，不能硬套同家族对比。
- HemoPI2及NTxPred2的既有全数据诊断未证明能改善通用毒性分类；专项终点阴性不等于总毒性阴性。SaProt选择/融合未证明稳定净收益；不重复直接加模块。

## 候选方法与证据
1. 分层困难对照、训练内交叉预测与受限修正：分别分析低Cys正类漏判、高Cys负类误报；同标签、近长度/来源/家族做对照；先用训练内交叉预测定义困难，再在训练折内开发受限修正。比较普通模型、简单固定权重、门控修正，评价整体/两组FN与FP、其他组、标记分层及成对置信区间。门控输入只能使用预测时可获得的序列、概率和可用结构信息，不能使用真实标签、审计标签或家族人工真值；各层嵌套防泄漏。现阶段没有证据门控可预测谁会纠错，需与简单模型对照，不能以结果反推给每个样本选择正确分支。
2. JTT：初始模型错题上采样再训练，论文原理见 https://proceedings.mlr.press/v139/liu21f.html 。错误不等于标签噪声或可靠困难，用户已试低Cys统一加权导致整体退化；只能在每个外层训练内部产生严格交叉拟合错题、限制权重，并以相同数据成本和标签疑点分层对照；不预设有效。
3. LfF：偏置模型强调容易学习的表面规律，让另一模型关注冲突样本 https://papers.neurips.cc/paper_files/paper/2020/hash/eddc3427c5d77843c2253f1e799fe933-Abstract.html 。可先以Cys计数/长度/组成训练一个简单探针，检验预测是否被这些变量解释；该相关性不是因果证据、也不说明Cys无生物作用。若探针显示问题，再比较受限学习；标签不确定会被误当偏置冲突，不能直接提高所有错题权重。
4. 带标签疑点的稳健学习：CoDis提出通过样本选择和两模型分歧兼顾难样本与噪声 https://openaccess.thecvf.com/content/ICCV2023/papers/Xia_Combating_Noisy_Labels_with_Sample_Selection_by_Mining_High-Discrepancy_Examples_ICCV_2023_paper.pdf 。该研究非肽毒性且噪声假设不同；高分歧/小损失均不证明标签正确。优先做敏感性实验，保护不丢少数真实难样本。
5. 监督对比：CAPTP原论文已有对比学习 https://pmc.ncbi.nlm.nih.gov/articles/PMC11654579/ ；AMCL用于多功能治疗肽而非我们的二分类 https://pmc.ncbi.nlm.nih.gov/articles/PMC12210482/ 。本项目首折已有实验，但低Cys正类漏判增加；继续前先冻结旧配置在其他折复验，评估不同组及整体，不对所有毒肽强制聚为单一机制。
6. Group DRO：最坏组训练可借鉴 https://arxiv.org/abs/1911.08731 ，但过参数模型需考虑正则及有限组证据；低Cys×原标签、高Cys×原标签为训练与评价分组，不能在推理时使用真实标签路由。目标组标签噪声、小组规模、1.5加权负结果使其优先级靠后。

## 推荐优先顺序
1. 复用现有完整OOF，建立原模型、低Cys加权、监督对比三个实验的同一折逐样本纠错/添错及低Cys原正、高Cys原负、带疑点/未标记分层表，明确哪些信号改善一类却伤害另一类。用已有实验，不再跑同样模型。
2. 使用训练内部的原序列特征和分组进行简单Cys/组成偏置探针，组隔离验证；判断规律是否仅由简单组成解释，缺标签可靠度证据时不宣称因果。
3. 若训练内可形成有稳定独立信息的纠错/添错规律，试固定配置受限残差或门控，对照无修正/普通残差，并跨折不同种子；标签只能训练时使用，推理不使用。
4. 仅在明确可靠性限制和交叉拟合隔离之后，尝试温和的JTT/LfF或Group DRO，与现有低Cys统一加权作对照，所有决策基于训练内验证。首折及旧OOF已反复观察，非新盲测；最终冻结后找同终点、严格同源去重的外部集，必要时补三种子完整融合。

以上均是研究候选，不保证整体指标提升；未实施新训练或更改权重。资料路径遵循本仓库要求。
