# 组成规律纠偏：核查与轻量试验

2026-10-31。搜索src及10月analysis中的debias/bias_model/product-of-experts/shortcut等，并读取既有组成探针和Cys方案，未发现与本试验相同的组成小模型参与主训练损失的实现；不能保证搜索覆盖全部异名历史实现。原有组成探针仅模仿概率、风险诊断和Cys分组加权不能冒充本试验。

使用fold0已有3830条基础模型训练样本的冻结三维节点摘要特征，和616条诊断验证。所有小主头同64隐藏单元MLP、同10轮、batch64、AdamW lr.0003/wd.01、seed42/123/2025三种子均值、相同训练与验证角色、阈值.5。不是对完整GHXTox进行端到端去偏。基础空间表示已由用过主头训练数据的三维模型产生，存在样本内特征问题；验证反复开发，非盲测。metadata索引沿用已核查数据顺序；组隔离检查通过。

组成模型采用长度+Cys数+20AA频率的逻辑回归；在主头训练样本中按既有序列group做3折交叉拟合，产生每条样本未参与组成模型拟合的logit。BCE对照正常主头；困难加权对照以组成小模型对原标签的错误概率为权重，截断[.1,1]、归一平均1；shortcut_loss方案在训练时用主头logit+固定组成logit算BCE，推理只用主头。后者是有偏模型组合损失的初筛，非因果去偏，不确保完全去除Cys信息，也不证明组成规律一定是错误捷径。未使用外部Test1/2，无疑点过滤，不按错题改标签。
