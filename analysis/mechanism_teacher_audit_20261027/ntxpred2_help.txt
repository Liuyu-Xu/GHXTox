        <section id="classification">
            <div class="card">
                <h2><span class="emoji">🔬</span> Classification</h2>
                <p><strong>NTxPred2</strong> classifies peptides and proteins as <strong>neurotoxic or non-neurotoxic</strong> based on their primary sequence.</p>
                
                <h3><span class="emoji">🔹</span> Model Options</h3>
                <ul>
                    <li><strong>ESM2-t30 (Peptide Model):</strong> For sequences <strong>7-50 amino acids</strong> long.</li>
                    <li><strong>ET (Protein Model):</strong> For sequences <strong>≥ 51 amino acids</strong>.</li>
                    <li><strong>ET (Combined Model):</strong> For sequences of <strong>mixed length</strong>.</li>
                    <li><strong>Default Model:</strong> ESM2-t30 (Peptide Model), selected for best performance and efficiency.</li>
                </ul>
            </div>
        </section>
        
        <section id="usage">
            <div class="card">
                <h2><span class="emoji">🚀</span> Usage</h2>
                
                <h3><span class="emoji">🔹</span> Minimum Usage</h3>
                <div class="code-block">
                    <pre>ntxpred2.py -h</pre>
                </div>
                <p>To run an example:</p>
                <div class="code-block">
                    <pre>ntxpred2.py -i example.fasta</pre>
                </div>
                
                <h3><span class="emoji">🔹</span> Full Usage</h3>
                <div class="code-block">
                    <pre>usage: ntxpred2.py [-h]
                   [-i INPUT]
                   [-o OUTPUT]
                   [-t THRESHOLD]
                   [-j {1,2,3,4}]
                   [-m {1,2,3}]
                   [-d {1,2}]
                   [-wd WORKING DIRECTORY]</pre>
                </div>
                
                <h4>Required Arguments</h4>
                <table>
                    <tr>
                        <th>Argument</th>
                        <th>Description</th>
                    </tr>
                    <tr>
                        <td><code>-i INPUT</code></td>
                        <td>Input: Peptide or protein sequence (FASTA format or simple format)</td>
                    </tr>
                    <tr>
                        <td><code>-o OUTPUT</code></td>
                        <td>Output file (default: <code>outfile.csv</code>)</td>
                    </tr>
                    <tr>
                        <td><code>-t THRESHOLD</code></td>
                        <td>Threshold (0-1, default: <code>0.5</code>)</td>
                    </tr>
                    <tr>
                        <td><code>-j {1,2,3,4}</code></td>
                        <td>Job type: 1-Prediction, 2-Protein Scanning, 3-Design, 4-Design all possible mutants</td>
                    </tr>
                    <tr>
                        <td><code>-m {1,2,3}</code></td>
                        <td>Model selection: 1-ESM2-t30 (Peptides), 2-ET (Proteins), 3-ET (Combined)</td>
                    </tr>
                    <tr>
                        <td><code>-wd WORKING</code></td>
                        <td>Working directory for saving results</td>
                    </tr>
                </table>
