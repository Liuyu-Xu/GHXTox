# 监督对比学习样本对可行性核查

复用现有6387条样本、统一UniProt家族侧表和5折训练角色；未改标签、未训练模型，也未使用Test1/Test2。每折只统计该折训练角色，不用外层留出标签建训练对。

候选定义：唯一完整家族一致、原标签相反、序列组不同、Cys同为<4或≥4且数量差≤1、长度差不超过较长序列20%。序列相似度为1−编辑距离/较长序列长度，是筛选代理，不是比对序列一致性；阈值0.5是探索性示例，不是生物学标准。

同一条肽可以参与多对，候选对数不是独立样本数；详细数据记录各折独立样本数及家族。两边无旧标记也不等于实验标签可靠。家族一致、序列接近不代表相同实验终点、物种或化学修饰。相反标签可能是终点不一致、分子状态不同或标注冲突，因此不能自动当成可靠的负对。

当前按这套严格探索条件，每折高Cys且相似度≥0.5且两边无标记者为0对；低Cys每折仅1—4对。样本太少，不适合以这些对为主要监督信号训练新网络，也无法确认这套严格条件是唯一合理方案。

已有KD原型残差v1/v2曾分别获得约+0.00304/+0.00287 MCC，未达到各自预设+0.005门槛；那是其他轻量模型与设置，不能当成GHXTox原型网络已经失败。见 ../../runs/kd_prototype_residual_report.md 和 ../../runs/kd_prototype_residual_v2_report.md。

下一步可先做普通分类+监督对比损失的受控试验，正负配对仅使用外层训练内原标签，不把有疑点当错标、不把未标记者当金标准；并对疑点样本剔除对比项而保留分类项做敏感性对照。必须预先确定批次配对、无正对处理、损失权重和各折内选参，不能用测试集选择。若要主张同家族近序列机制，需要先找到可核验终点和分子状态的更多数据。
