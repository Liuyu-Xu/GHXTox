# 无LoRA家族加权：通俗结果

本次一折、一个种子；1291条留出，其中MCD/NDBP只有4条。三个方案：A无额外加权；B给低Cys原正类1.5倍；C在B基础上给MCD/NDBP原正类总权重2倍。

|一维模型|A 原训练|B 低Cys加权|C 再加家族权重|
|---|---:|---:|---:|
|MCC ↑|0.8000|0.8241|0.7840|
|错题数 ↓|104|90|112|
|MCD/NDBP漏判|4/4|4/4|4/4|
|其他原正类漏判|48|54|54|
|原负类误报|52|32|54|
|AUPRC ↑|0.9310|0.9259|0.9255|

B总错题少14条主要是误报减少20条，同时其他正类漏判多6条；MCC差的95%重采样区间跨零。C比B总错题多22条，4条目标全部仍被漏判。目标中3/4在C相对B的一维概率下降，1/4上升，单折只能描述这一现象，不能证实家族加权普遍无用。

B被加权的251条训练样本中，120条有旧标签疑点标记；无标记也不能当标签已证实正确。权重按原标签及家族字段指定，未验证毒性机制。研究对象、家族和该折是在看过既有错误后选择，不能作为盲测。只有一折一个种子，尤其目标仅4条，结果不能直接部署或做稳定泛化结论。

B若继续研究需先在其余折、不同种子复验，并同时看漏判与AUPRC；C当前不应推广。固定历史3D概率的条件融合结果见完整报告，不等于完整三种子系统重训。[报告](REPORT.md) · [分层结果](metrics.json) · [核验](verification.json)
