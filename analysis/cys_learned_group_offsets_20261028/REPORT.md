# 学习低、高 Cys 组统一概率调整幅度

## 方法

使用原始完整 GHXTox 一维序列与三维结构融合后的 6387 条历史 OOF 概率，不重新训练主模型。轻量模型只有两个待学习数值：低 Cys（0–1）统一加多少，高 Cys（≥6）统一减多少；2–5 个不调整。使用开发四折的正负样本、平均二元交叉熵加 0.01 倍两参数平方惩罚来训练，范围分别限制为 [0, 0.15]、[−0.15, 0]。超出 0–1 的概率截断。评价保留折，轮流五次；全程沿用原始阈值 0.4702225653。不输入真实标签来判断某个样本属于哪一类。未使用 Test1/2。

| 评价折 | 低 Cys 加 | 高 Cys 减（有符号） |
|---|---:|---:|
| 0 | 0.000693 | −0.000918 |
| 1 | 0.002031 | 0 |
| 2 | 0 | −0.001745 |
| 3 | 0.000399 | 0 |
| 4 | 0.000099 | 0 |

| 方法 | 总错 | MCC | AUPRC | 相比原模型纠错 / 新增错误 |
|---|---:|---:|---:|---:|
| 原完整 GHXTox | 327 | 0.8733 | 0.9577 | — |
| 上次固定阈值、按开发集 MCC 选择偏移 | 328 | 0.8728 | 0.9506 | 4 / 5 |
| 本次学习偏移 | 328 | 0.8729 | 0.9573 | 0 / 1 |

低 Cys 有毒 262 条，漏判均为 140；高 Cys 无毒 240 条，误报均为 50。新增的一条错误是高 Cys 有毒样本被漏判。低 Cys 无毒共有 3537 条，高 Cys 有毒 1063 条；训练要考虑所有样本，不能只根据希望纠正的有毒/无毒样本调节。优化目标是整体概率误差，并非直接优化 MCC；小偏移可能反映原概率在整体交叉熵下不支持较大统一调整，不能认定其唯一原因。

## 局限

沿用原始完整模型的历史 OOF。后处理训练未用当前评价折标签，序列组不交叉，但上游预测的模型训练和历史校准/阈值选择并非完整嵌套；因此这不是严格独立验证。调整方向、上限和惩罚系数是本次固定试验条件，不能据此否定所有可学习调整方法。原标签不一定都可靠。两参数模型是每组统一调整，不是根据具体序列和结构差异逐条调整的门控。

具体结果见 selection.json、metrics.json、fold_metrics.json、predictions.json；analyze.py 可复现。下一步如继续探索，应先分析各组内概率分布及临界值附近的正确和错误样本，再用严格嵌套方式验证具有样本区分能力的轻量模型。
