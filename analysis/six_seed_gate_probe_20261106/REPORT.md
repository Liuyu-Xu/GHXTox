# 六种子与三维分歧：自适应选择可行性初查

## 结果

现有数据中，两分支何时有分歧存在可测线索，但本次小型选择器没有比简单固定融合更好，不能作为已验证的自适应融合或直接部署。特别是少数类别太少：第4折不满足预先设定的每类至少10个独立训练序列组，选择器在该折回退纯一维。该门槛是保守的操作门槛，不意味着超过10组就已经足够。

## 第一次预检：样本不足

每个外折的校准集分为Platt拟合半部和探针训练半部，后者分歧样本分别为20、18、22、14、24条；其中三维判断正确的独立组数为6、6、5、7、6，全部低于预设每类10组，不训练门控。简单的“离阈值较远选谁”在各折分歧样本上可区分一些三维正确与错误，但强行选择会同时添错；详情见 summary.json。协议见 PROTOCOL.md。

## 补充交叉校准预检

为扩大校准集可用样本，看过第一轮样本数和简单距离基线后增补方案（CROSSFIT_PROTOCOL.md）：每外折内部将校准集按序列组分为两半，互相拟合Platt生成校准集交叉预测，并以两分支判断有分歧者训练小型逻辑回归；外折预测则用完整校准集拟合的Platt。仅概率组输入一维分数、三维分数及一维六seed的原始概率标准差；另一组再加序列长度、Cys=0和Cys≥7指标。模型训练可使用原标签构造“哪边判断正确”的目标，外层推理只接收预测时可得的信息。无真实标签、是否错、家族或实验信息进入推理。两条规则固定输出>0.5才选择三维，其余选一维；不是连续动态权重。

本轮交叉拟合后每折分歧训练样本42、40、41、27、42；三维正确独立组15、11、12、8、16。外折分歧总319条，其中三维对93、一维对226；这些数字只用于事后评价，不能在推理时知道。只在有分歧的外折中，简单距离分数的逐折AUROC为0.805、0.849、0.721、0.684、0.671；概率探针在可训练4折分别0.659、0.780、0.612、0.499；加Cys和长度分别0.631、0.817、0.677、0.624。AUROC反映有一定排序线索，不能把它等同真实可用的选对率或分类改善。

## 结论与后续

目前可用于后续研究的不是“新门控已有效”，而是：两路有分歧，简单概率距离在某些折能排序“哪边正确”的线索；但训练数据少、类别倾斜，转成离散选路后添错多于纠错。下一步如继续，应先查同一训练折可获得的真实pLDDT及结构质量字段、上游3D折外/选模谱系，并评估是否有足够分组样本；如果无法证明上游隔离，不能以新分折门控宣称严格无泄漏。不同目标、分数或正则需要新冻结协议和未见评估，不能在当前五折反复试到好看。固定融合及当前模型不变，Test1/Test2未参与。

复算入口 run_probe.py、crossfit_probe.py；验证 verify.py 检查6387条对应、组隔离、路由规则及MCC；完整五折、组和逐样本输出见 summary.json、crossfit_summary.json、crossfit_outer_predictions.csv。此前0.72/0.28原结果和新完整校准结果数值不同，原因是本次校准数据量发生变化，不能直接跨表比较或归因门控。
