# 补充探索：校准集内部交叉拟合探针

最初保守方案的选择半部只有14–24个分歧样本，五折均未达到每类至少10个序列组。为检查是否存在可研究的信号，在查看该预检数量及简单距离基线后，新增以下方案；这是方案修订后的探索性研究，不是事前盲测。

每外折的calibration集按与原实验相同的固定随机种子分为互不重叠序列组的两半A、B。先以A的标签分别拟合序列/结构Platt并预测B，再以B拟合预测A；每个calibration样本由未看过它所在组的校准器生成两个分支分数。将交叉校准后两路在阈值0.4702225653处不同的样本用于训练探针；训练目标是三维是否相对原标签正确。使用两组预先固定输入：A={序列概率、结构概率、六个一维原始seed概率标准差}；B=A+长度+Cys=0+Cys≥7。训练阶段的分支概率不使用样本自己的标签校准；只使用该样本标签构造探针目标。StandardScaler和逻辑回归C=0.1仅在本折校准集中的分歧样本上拟合；每类少于10个不同序列组时跳过该折。

本折结构/序列最终校准器用完整calibration拟合，产生未参与校准和探针训练的对应外折test预测。探针根据训练时固定的0.5输出选择分支，绝不以外折真实标签作为输入；同时保留预测概率衡量区分能力。简单对照是同一校准器下的纯一维、固定0.72/0.28、两分支距共同阈值较远者；报告整体MCC、AUPRC和纠错添错、Cys=0和≥7且按原标签分层。这个是离散分支选择器可行性诊断，不等于已经实现或验证连续自适应权重。

所有方法共用本次新校准，不能与此前半集校准的数值直接混表。虽然校准、探针、外层评价按组分离，每个探针训练样本的校准预测与外折使用的完整calibration校准器存在分布差异；较小且数据重复探索，分组OOF对早期完整上游谱系不自动提供无泄漏认证。五折并非独立盲测，不读取Test1/Test2，不根据外折筛选再反复调参数。本轮不将方法部署、不用纠错标记作为推理输入。

## 追加固定比例对照

看到上述预检结果后补充：在每折全部calibration的交叉校准预测上，从三维权重0、0.1、0.2、0.28、0.3…1.0中按MCC选择一个权重，阈值固定历史值，同分优先接近0.28，再锁定在外折使用；不使用外折标签选择。该对照利用与探针相同的开发数据，旨在衡量调整一个全局比例的竞争力。属于事后增补的内部探索，不是预注册确认。
