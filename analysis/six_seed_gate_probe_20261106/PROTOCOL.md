# 一维与三维分歧：训练内可预测性预检

本预检只使用之前确定的五个训练外折对应的 calibration 和 test 角色。每折复用先前按序列组划分的Platt拟合半部和选择半部；使用先前参数校准，固定两个分支分类阈值0.47022256531284556。将 selection 半部里两分支判断不同的样本作为本折探针训练集；外层 test 中判断不同者为评价样本。每条的训练目标为在该样本上三维判定是否与原标签一致，仅在有监督训练/事后评价使用；推理输入不含标签、分支对错、历史错误或Test1/Test2信息。结构已计算，故不是结构计算前的路由。

预先比较：简单基线始终选一维；以各自距阈值绝对距离较大者为分数置信度基线；小逻辑回归A仅用预测时可得的两分支概率及六种子一维原始分数标准差；模型B再加入长度与极端Cys指示（Cys=0、Cys≥7）。标准化仅用探针训练样本拟合，C=0.1，固定0.5判断，禁止按外折结果调参。仅当训练分歧样本中每一目标类别均至少10个不同序列组、且两类均存在，才拟合对应折；否则该折记录不足并不输出虚假训练结果。汇报逐折训练与评价的纠正/添错、目标类别数、组数和预测概率AUROC；不将预测是否选对等同最终MCC。

本任务为可行性预检，不保证能优化0.72/0.28连续融合、没有自动晋级，不在Test1/Test2拟合或选规则。现有骨干输出非完整嵌套谱系已知限制；保持当前外折不参与门控拟合并不认证结构上游全流程无泄漏。研究数据反复探索，结果不是盲测。使用的三维是重训骨干且为一个种子，不是部署checkpoint；不使用不可获得的pLDDT。阈值历史上为融合阈值，作为分支一致性的诊断，不代表两分支阈值最优。
