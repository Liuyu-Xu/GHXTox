# 上游新版：删除额外Transformer的核对

核对时间：2026-10-27。上游提交：`60854abd61c4f1fd8b65c2eb586a7d03d7588130`，标题 `Prepare publication-ready transformer-free default`。本轮仅读取公开源文件，未合并、覆盖本地代码或训练。

## 已确认

- 默认结构子模型的 `num_sequence_layers` 从2变0，SequenceBranch.encoder用Identity旁路。残基输入投影、位置嵌入、归一化仍保留；不是删除整个序列输入支路。
- ProtT5、ESM2预训练架构未删除；三层EGNN、化学位点消息传递、cross-attention、pLDDT门控保留。
- hidden_dim=128、前馈512时，额外Transformer每层198272参数，两层共396544参数；以PyTorch相同层实例计数确认。该数仅指被删除层，不包括冻结PLM，不能直接宣称整个系统按同等比例缩小或提速。
- 新默认结构权重：`runs/default_no_inner_transformer_20261023/best_model.pt`。6387条全量、seed42、固定6轮重拟合；不能用全量训练预测替代OOF。
- 新融合为序列0.76、结构0.24，阈值0.5063534554819765。旧版为0.72/0.28及0.47022256531284556。

## 尚不能确认

公开树未包含这次消融的逐折OOF指标、配对区间或新旧总参数效率表，README只称validated。因此目前不能独立量化指标提升多少或证明统计稳定。默认训练还从仅化学位点可训练改为全参数可训练，融合权重和阈值也改变；直接比较两个最终默认配置不能把全部提升单独归因于删Transformer。

## 对后续研究的影响

之前SaProt研究与旧完整模型的交集仍是历史分析，不能自动迁移为新版错误地图。先取得新版真正折外预测、划分和配套消融结果，确认新版相对旧版的改善，再以新版作为SaProt增量比较的主要基线。没有这些文件前，不重复训练也不拿新版全量拟合输出冒充OOF。

可能解释：ESM2本已提供上下文，额外两层可能冗余或更容易过拟合。这只是待验证假设，不是已证明的生物机制。
