# 低Cys短板的整类家族背景核查

2026-10-27。仅补齐缺少的家族字段并关联已有预测。没有重标、删除、重新配对、模型前向、训练或阈值/权重搜索。当前结果是历史预测的背景诊断，不是新留出验证。

## 结论

**低Cys不是一个同质难类，不能把所有低Cys漏判解释为同一条Cys捷径。**家族之间的表现差异很大；严格同家族内的高低Cys共同支持仍不足，所以没有证明模型因果依赖Cys。可靠性数值权重仍不具备证据基础。

本轮实际补齐了以前覆盖不对称的正确背景，而不是重新看几条旧错题。已有家族注释从205/6387扩展至3938/6387；两版都正确的低Cys比较池从2/213有家族变为168/213。所有旧家族注释在新字段中均恢复，没有旧记录丢失或选择性替换。

## 1. 怎样对称补齐

旧全量UniProt TSV含名称/功能但不含SIMILARITY家族字段；205条详细家族来自偏向旧错题的JSON缓存，不能直接用于公平家族比较。本轮按不依赖对错的规则，一次取所有reviewed、长度7–50的条目，包含序列、accession、名称、物种和Sequence similarities，共13150条外部记录。只按完整序列精确匹配6387条，不把最近序列自动分配给某家族。

当前与旧缓存均为UniProt release 2026_03。仍保留取回日期/URL/响应头/SHA，不能把reviewed家族注释当成实验毒性真值。

## 3. 严格同家族高低Cys对照是否足够

主层使用完整SIMILARITY声明，包含亚家族层级；次层单独使用其第一句上级家族，属于更宽背景的探索性汇总；名称正则代理另列，不能冒充已确认家族。原正类完整家族唯一分配覆盖816条，246个家族。

- 完整家族层有10个家族同时出现低/高Cys，合计85条。
- 没有一个达到预先记录的每侧至少5个独立序列组的最低描述覆盖要求。该要求只是本轮覆盖门槛，不是统计功效保证。
- 上级家族层有3类达到该覆盖：PLA2、venom metalloproteinase、long scorpion toxin superfamily。但这比主层更宽，不能包装为严格家族控制通过。

|上级背景（探索性）|低Cys：旧/新错数/总数|高Cys：旧/新错数/总数|疑点限制|
|---|---|---|---|
|磷脂酶A2|6/39、9/39|0/9、0/9|两侧全部有旧主标记|
|毒液金属蛋白酶M12B|8/13、5/13|0/8、1/8|低Cys侧全部有标记，高Cys侧3/8有标记|
|长链蝎毒素上级族|3/7、3/7|0/7、1/7|两侧全部有标记|

这些表面上支持错误偏向低Cys，但片段对象问题与亚家族差异没有排除。去掉主标记后，上述三个背景都失去低Cys比较臂；不能据此声称在可靠家族样本中复现。

原负类也全部保留：完整家族层21类同时含高低Cys，达到每侧5组者只有核糖体蛋白bL33家族；它不等于原富Cys共误64条的统一背景，不能以这一个背景代表所有负类。

## 4. 低Cys内部，哪些整类判得好、哪些判得差

下表来自所有原正类中低Cys成员的统一上级家族汇总，展示不同模式；没有据错误率筛掉其他家族，全部主层/次层面板在ALL_FAMILY_PANELS.md及JSON。

|上级家族背景|低Cys n|旧漏判|新漏判|有旧主标记n|如何解释|
|---|---:|---:|---:|---:|---|
|缓激肽增强肽|17|0|1|0|模型能够识别这类低Cys原正类，是重要反例|
|MSDIN真菌毒素|31|1|8|7|同为低Cys，旧版大部分能识别；新版变化也不统一|
|Cupiennin上级族|23|7|9|1|有错有对，可作为类内背景诊断候选；上级族含多个亚家族|
|MCD上级族|6|5|6|0|保留整类困难线索，但数量小且上级族包含mastoparan/bombolitin等不同分支|
|NDBP上级超家族|5|5|5|0|保留整类共漏线索，不能因无标记就称可靠，更不能当统一机制|

这些不是同终点、同化学身份的毒性金标准比较。NDBP的成员含不同作用背景，不能直接把这5条全当溶血；MCD等家族标签不等于已证实错因。Cys在结构中有真实含义，强制模型完全忽略它也可能损害真正毒肽识别。

另外，Cupiennin上级族去掉唯一主标记者后有22条，全部Cys=0，旧错6、新错8，同时也有大量正确样本。它显示Cys计数本身不能区分该类对错，但没有证明剩余区别一定来自几何、某个机制或某种修饰。此前空间特征/化学状态的负结果仍然保留，不换个名称重做。

## 5. 旧正确对照补齐后发生什么变化

旧151组成边和27家族/名称背景边共178条来源记录，其中同一对peptide_251/139在两个档案中各出现一次，因此只有177个不同有向样本对。此前“178独立边”的说法需按此区分，不能当178份独立证据。

- 178条来源记录中，22条现在有共享完整家族，28条有共享上级家族。
- 低Cys原正类case有共享完整家族的不同样本对共16对；7对同折，6对两边都无旧主标记。
- 其中14对Cys数量完全相同；16对均未跨越Cys<4/≥4分层。

因此它们可用于描述同类背景下“为什么有的对、有的错”，却不能验证跨Cys因果作用。许多对照为跨折、同参考标记或分子形式待确认；原配对的组成/近序列条件与限制沿用，不新增优化、不把补家族字段当新增实验支持。完整逐边证据已保存。

## 6. 对接下来模型试验的具体约束

1. **先以家族/序列背景组织困难群体，Cys保留为分层指标。**不要把全部421条低Cys正类绑成一个机制，更不要设计“强制忽略Cys”的网络。
2. **可靠性感知权重继续暂缓。**现有原标签证据链未完整恢复；没有主标记、家族明确或教师预测一致，都不能自动作为高可靠标签输入。
3. 下一项可准备受限的困难群体平衡训练对照，检验是否改善具体整类与完整分类；它是经验效果试验，不是Cys捷径因果结论。原训练必须作为对照，所有四类、正确背景、添错和原疑点组一并报告。当前尚未运行任何这类训练。
4. 权重/群体定义只能在外层训练数据内部形成，不能从当前151共漏名单生成权重，再把同一批OOF当新验证。只训练小头的正结果也不能直接记到完整GHXTox名下。
5. 不再为本项无限扩展文献核查。统一字段已经补齐，下一次工作应落实可运行的最小训练/评价协议、实际可用表征与计算成本；若权重/特征不能支持完整隔离的比较，应明确缺什么，不能继续用漂亮分层表代替效果试验。

当前可确认的是类别背景差异和注释覆盖不平衡；尚未确认具体生物机制或最优神经网络。
