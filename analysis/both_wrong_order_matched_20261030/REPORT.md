# 一维、三维共同错误：残基排列配对探索

之前完成过融合错误的整体特征比较、少量家族对照及 SaProt 顺序扰动，但未针对历史一维和三维同时错误的两类重点样本做这项全组配对。本文使用已有6387条训练 OOF，不使用测试集，不重训。

目标为低 Cys（0–1）原标签有毒的107条共同漏判、高 Cys（≥6）原标签无毒的37条共同误报；对照为相应标签、同Cys组的两分支均正确样本。限定同折、Cys数完全相同、长度差≤5、已有片段/冲突标记状态相同、序列聚类组不同；每条对照最多使用一次。优先选择有同一已有家族注释的对照，其次按长度差和氨基酸组成近似度选配；并未要求相同家族或序列相似度达到指定阈值，也未约束每个序列聚类组只能使用一次。条件和结果为探索性，不作因果或预注册假设检验。

63对低Cys中错误样本疏水残基相邻比例高于对照36对、低23对、相同4对；中位数差0.050。高Cys 18对中归一化Cys平均间隔高12对、低6对，中位数差0.0126；Cys跨度高12、低6对，中位数差0.0737。均仅是描述性观察，家族/来源/组成尚未充分控制，候选对照选择在同数据上完成，不能称为稳健规律或解释模型错误。低Cys 0–1无法计算Cys之间间隔；仅10对两侧能计算Cys邻位疏水比例，不足以推广。

每组的未匹配 ID 与逐特征覆盖见 summary.json；逐对序列、组、标记、特征和差值见 matched_pairs.csv。实际标签不是实验金标准，核查标记不代表标签错误；无标记也不等于可靠。阈值、上游预测与校准非完全嵌套，本研究只用于产生假设。没有观察到可证明的生物机制或模型净收益。
