# SaProt受控排列诊断（2026-10-27）

后续更新：[完整20AA组成检验已完成](../saprot_composition_20261027/REPORT.md)。组成可重建部分总体教师行为，但未复现分类收益；本文末尾的组成探针任务已完成，保留原阶段叙述。

主要发现与原猜想相反：在成分和长度不变的扰动下，SaProt全结构掩码专家通常比ProtT5专家反应更小，而不是更依赖精细排列。这个差异在纠错组和添错组都存在，并不能证明SaProt更懂毒性机制。均值表征本身也有差异，不能仅归因于ProtT5额外使用max/std。下一步应排除完整氨基酸组成及非线性组合的解释，再设计蒸馏。

## 覆盖范围及输入边界

763条原样本：包含全部450条同规模4成员基线错题、任一融合新增错题、固定哈希分层正确背景及全部旧配对对照。按全掩码融合角色分为96纠错、62添错、354仍错、251仍对；不是763条随机代表性队列。所有类别全体纳入或按预定规则抽取，不围绕一两例解释。原标签仅用于原样本分层，不赋给扰动序列。

每条4种扰动×2重复，保留全部候选6104条；566条Cys移动记录未发生改变（主要无Cys）而不进入有效比较，其他模式均有效。共5538条有效扰动，5532条不同扰动序列，另763条原序列。各模式保持长度、氨基酸多重集和Cys数量；非Cys扰动还保持Cys全部位置不变。没有训练新神经网络或预测新三维结构。

改变AA序列后不能沿用原3Di结构token。因此本轮是序列与全# SaProt专家的诊断，不评价结构SaProt扰动，更不能解释其31条独有纠错为三维机制。两个单专家均平均相同2种子；另保留原4成员基线及固定概率融合响应供复查。每条扰动使用其原样本的held-out fold模型，不使用原样本参与训练的模型。

原输入对齐：重新编码763原序列后，ProtT5/SaProt特征最小余弦相似度约0.99982/0.999999，原4成员基线及SaProt2成员判断与旧记录均100%一致。平均概率差0.000620/0.000194。所有扰动均相对本轮重新编码原序列比较，避免batch/精度差被误当扰动效应。

## 纠错整类：平均预测概率改变多少

下面比较96条原全掩码融合纠错；Cys移动仅59条可实际改变。数值为每条两个重复的绝对概率变化均值再按原样本平均，不是毒性下降/上升，也不是扰动后的准确率。

|扰动|有效原样本数|改变位置比例|ProtT5两种子专家|SaProt两种子专家|
|---|---:|---:|---:|---:|
|局部打乱非Cys（每4位一块）|96|60.6%|0.5140|0.1019|
|全局打乱非Cys，固定Cys位置|96|81.5%|0.5032|0.1665|
|移动Cys，保持其他残基相对顺序|59|55.4%|0.4761|0.0645|
|全部残基打乱|96|89.3%|0.5441|0.1662|

16个预定敏感性比较（4模式×纠错/添错×概率/标准化logodds）中，SaProt减ProtT5的均值均为负，99.6875%原序列群配对bootstrap区间均未跨零；每个比较五折方向也均为负。尺度控制以各模型原折全部OOF分数标准差归一化，差异仍存在，故不能仅用原始分数单位解释。仍可能受剩余非线性、饱和和表征几何差异影响。区间条件于这些固定模型和2次扰动，不是机制确认或独立外部验证。

这个现象不只出现在纠错样本。全局非Cys打乱时：

|原样本角色|样本数|ProtT5绝对概率变化|SaProt绝对概率变化|
|---|---:|---:|---:|
|融合纠错|96|0.5032|0.1665|
|融合添错|62|0.4892|0.2197|
|融合后仍错|354|0.2677|0.1865|
|融合前后正确|251|0.2572|0.1384|

因此“对排列更不敏感”不是只标识纠错的特征，也可能在真实需要精确顺序的毒肽上保留错误。随机打乱大量残基可能严重偏离天然肽分布；不能把不变性都叫生物学鲁棒性，也不能根据这些变化强行要求学生对排列不变。局部/整体模式改变比例不同，未将其幅度直接当作局部机制强弱排序。

## 两个必要混杂检查

### 已有最小Cys间距输入

ProtT5基线输入不仅有语言模型表征，还有PhysChem9，第9项为最小Cys间距。Cys移动时既会改变表征，也可能改变这条已有输入。将原9项理化特征全部保持不变、仅换扰动ProtT5表征后，纠错59条的平均概率变化仍0.4800，原完整扰动为0.4761；单独改动理化路径的平均概率差约0.00769。故本轮较大的基线反应不能主要归因于这个显式间距字段。所有非Cys扰动的9项输入均保持到1e-6内，全部扰动前8项成分输入同样保持。

### 均值、最大值、标准差汇总方式

SaProt原头只用mean480；ProtT5原头用mean/max/std各1024维。事后有界跟进只在冻结基线头中替换一个汇总块，其他块和PhysChem9固定，不重训、不新生成扰动。

|扰动（纠错类）|仅替换ProtT5均值块|仅最大值块|仅标准差块|三个块同时替换|
|---|---:|---:|---:|---:|
|局部打乱非Cys（每4位一块）|0.2943|0.3410|0.2944|0.5140|
|全局打乱非Cys，固定Cys位置|0.3388|0.3371|0.3247|0.5032|
|移动Cys，保持其他残基相对顺序|0.3698|0.3391|0.2891|0.4800|
|全部残基打乱|0.3742|0.3509|0.3634|0.5420|

即便只换ProtT5的均值块，头的反应仍明显，不支持“全是max/std造成”的简单解释。但这不是训练一个mean-only模型的公平性能比较；混合原/扰动块可能离开自然表征流形，且非线性头的块效应不可直接相加。

直接比较同为均值的表征：全局非Cys扰动在纠错96条上的余弦距离，ProtT5约0.2887、SaProt约0.0314；Cys移动对应0.2593/0.0116。差异已存在于均值表征，并非只有头输出。不同预训练目标、嵌入几何与维数不同，这些数值不表示表征质量高低或毒性机制强弱。

## 相近背景与成员替换

复用全部旧配对覆盖样本，本轮针对全掩码候选实际比较11对纠错↔仍错和35对纠错↔始终正确；Cys移动两侧可变的分别8/21对。案例减对照的SaProt标准化敏感性差，在非Cys/全部打乱方向多为略正、Cys移动略负，没有形成明确且足量的特定家族纠错规律。配对量有限，保留逐对数据而不提升为家族机制证明。

另外，96条“相对4成员基线纠错”中，16条在原2成员基线本来已经正确。融合同时替换了部分基线种子，不能把96条全部归因于教师独有知识。本轮主敏感性比较用相同2种子专家以控制成员数，但原角色仍按已冻结4成员参照，不按新结果挑纯案例。

## 对增益原因的更新

可以支持：SaProt提供了一个对大幅序列顺序扰动反应更小的表征/判断来源；融合互补可能部分来自不同归纳偏好，而非SaProt更敏锐地识别局部顺序。这个“较不敏感”横跨纠错和添错，是模型行为差异，尚未证明它造成自然样本上的分类提升。

不能支持：SaProt学会了某个新溶血/二硫键机制；天然肽毒性不依赖顺序；扰动肽保持原毒性；越不敏感越好；强制所有学生对打乱序列保持原判断就能提升分类。当前也没有证明三维信息在起作用。
