# 下一项受控实验

本轮证据将问题收敛为：在实验对象和毒性终点一致的前提下，GHXTox 是否仍然漏掉低 Cys 的膜活性肽；若存在，膜选择性相关信息能否比一般困难样本加权提供更多帮助。

本文件是候选协议，尚未对新数据集开始性能评估；需要先确认符合条件的记录数量。不得把本轮错误重新贴标签后称为独立验证集。

## 第一阶段 先恢复实验证据

1. 每条记录保留完整序列、N/C端修饰、二硫键连接、环化/非天然残基、成熟体/前体/片段关系、物种、原论文DOI和精确表格位置。
2. 片段条目的整体蛋白活性不能继承给孤立短序列。只有证据明确测定该化学实体时，才可用于相应终点监督。Fragment不自动等于阴性，也不自动全部删除。
3. 区分已测阳性、指定条件下已测阴性、未测、未知、冲突。毒液来源、Toxin关键词、同源功能预测不能替代活性测量。
4. 优先追查H2C及其他低Cys完整肽的红细胞实验；pc16a/pc16c、G9.1和蛋白N端片段先作为标签/实体审核案例，不能作为已知机制正负配对。

## 第二阶段 固定一个终点

第一候选为人红细胞溶血，直接保留浓度-响应或HC50；不把昆虫神经效应、脑室注射行为和哺乳细胞增殖抑制混合成同一终点。

若需要二分类，可在查看新面板模型结果前采用已发表HemoPI2的HC50=100 μM界限作为预先指定的操作定义（不是普遍安全界限）。HC50明确≤100 μM为该定义下阳性；明确>100 μM为阴性。诸如HC50>50 μM不足以判定位于100 μM界限哪一侧，应保留删失状态。固定浓度的单点溶血百分比不能硬换算成HC50。

物种、温度、作用时间、红细胞比例和肽修饰须记录。优先形成实验条件相近的子集；不能为了增大样本量将不同单位、不同终点直接平均。

## 第三阶段 先评估现有模型

- 主分析：当前GHXTox完全冻结的单结构推理；三种子序列分支；只含Cys数、长度、净电荷、平均疏水性的简单组成基线。简单基线只能用开发部分拟合。
- 主分层：Cys<4/≥4，同时报告连续Cys分布；阈值4来自本轮探索，不能再宣称是事先独立发现。
- 指标：AUROC/AUPRC、Brier、固定阈值敏感性/特异性及混淆矩阵；保留序列组依赖的配对bootstrap区间。小样本时不把单点差异当成显著改进。
- 仅有当前精确UniProt匹配且未标Fragment，仍不足以称为已验证完整实体或金标准；需要回到原实验。

## 第四阶段 再检验纠错

先比较固定阈值/校准、增加序列集成、通用困难样本加权等解释，再比较具有膜选择性动机的表示或配对突变监督。所有候选选择、阈值、融合和校准必须位于外层训练部分之内。

原有OOF输出有全体OOF校准/操作点选择，部分相关历史结构谱系有留出折checkpoint选择记录，不能将其简单拿来训练二级纠错器后报告为严格嵌套提升。需要重新生成具有可审计谱系的内外层预测，或使用预先冻结模型在新面板上评估。

外部面板与原训练集必须做精确去重和全局比对；建议先冻结比对方式、身份计算分母和覆盖率，再设主界限（例如身份≤70%、双向覆盖≥80%），并单列≤40%的更严格敏感性分析。样本不足时应报告不可估计或宽区间，不得反复放宽筛选直到结果有利。

同一母体/家族、同一论文或实验室尽量整体分组。新数据库发布日期不等于实验首次测量日期；审查训练/开发接触历史，不能把重新汇总的旧数据称为前瞻性数据。Test1/Test2继续仅作历史对照。
