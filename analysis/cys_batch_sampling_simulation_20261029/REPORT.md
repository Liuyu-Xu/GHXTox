# Cys 分层 batch 采样模拟

只模拟既有五个外折的训练角色，未训练模型，未读取测试集标签。每批16条，每轮步数=训练样本数/16向上取整（236–242批）。按六类固定配额抽取，每批限制序列组不同；优先抽取本轮被抽次数最少的样本，同次数内随机选，随机种子固定。只在对比学习中排除已有疑点标记，分类损失保留全部样本。未标记不是标签金标准。

|方案|低Cys 有毒/无毒|中Cys 有毒/无毒|高Cys 有毒/无毒|低Cys有毒平均抽取次数|高Cys无毒平均抽取次数|
|---|---|---|---|---:|---:|
|轻度|1/4|2/3|5/1|1.44–1.61|1.58–1.82|
|适度|2/3|2/3|4/2|2.87–3.21|3.15–3.63|
|较强|3/3|1/2|4/3|4.31–4.82|4.73–5.45|

适度组中，两个重点少数群体每轮单样本最多抽4次；较强组分别最多5次、6次。这是模拟观察值，非未来训练的严格硬上限。每轮抽取步数固定，因此增加少数群体的同时其他群体平均抽取变少；这种权衡是有意的。

每个有效锚点要求同batch、同Cys组、未标记、不同序列组中至少一条同标签和一条异标签；属于SupCon有效性，不是生物学证据。适度方案未标记锚点有效比例：低Cys 63%–69%，中Cys 77%–79%，高Cys 88%–92%。部分不生效主要因疑点样本不能参与对比、同batch样本构成等；要比较两类损失，必须记录各组参与率和损失尺度。标签用于训练采样与构对，推理不使用标签。

建议以适度方案为固定试点；有意过采样，不保证提升。预先固定BCE标准随机采样、相同分层采样+BCE、相同分层采样+BCE+普通对比、再增加Cys组内对比等对照，固定训练步数和重复种子，诊断少数样本、另一标签群体、中Cys和总体MCC/AUPRC；旧fold3结果采样不同不能当等采样对照。结构采用既有3D条件融合并报告，与历史三种子完整系统区别。若继续应先一折试运行，不以历史测试集选配置，待确认资源后再服务器运行。

模拟未核实实验终点和分子形式，未验证损失权重、泛化及显存速度。details见 results.json，simulate.py可复现。
