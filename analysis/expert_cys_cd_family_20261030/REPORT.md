# 一维/三维互补与 C→D 样本分布

## 范围
复用 6387 条历史五折 OOF 分歧表与 B/C/D 三种子 OOF，无重训、无 Test1/2。分支阈值沿历史分歧表：1D 0.3920986716、3D 0.677819；融合阈值 0.4702225653。C/D 均独立使用全 OOF Platt 后以 0.72/0.28 融合历史 3D；校准非嵌套，两种概率受训练及校准共同影响。历史分支分组与 C/D 不是同一模型版本。长度按 ≤30、31–50、>50 个残基作描述性分组，不代表生物边界。

## 历史分支（数字依据原标签）
|群体|总数|两路均对|一维错三维对|一维对三维错|两路均错|
|---|---:|---:|---:|---:|---:|
|0–1 Cys 有毒|262|94|8|53|107|
|≥6 Cys 无毒|240|167|16|20|37|

原模型两路共同错误在两个重点群体分别为 107/262、37/240；以当前分支的二值判断直接挑选的理想上限无法修复共同错误，但概率再组合、重新训练或不同阈值可能改变结果，不能说所有融合皆不可能修复。所谓理想挑选需要事先知道标签，不可部署。两路各自阈值不同，两路判断均错并不必然意味着固定权重概率融合也错。

## C→D
融合结果共 112 条改变，其中纠正64、新错48。112条分布于109个既有序列聚类组，3组各有2条，其余各1条；这个聚类用于分折，并不能证明不同组之间无同源关系、无家族关联。112条中37条无可用家族注释，最多的已注释家族是磷脂酶A2：9条（纠4错5），其余已注释家族每项不超过2条；多重注释会导致家族统计重叠。不足以判断全部家族覆盖与富集，不能据此证明家族泛化。

低 Cys 有毒21条变动，纠12新错9，涉及20个聚类组、5个折；5条无家族注释，8条有已有核查标记。高 Cys 无毒8条变动，纠2新错6，涉及8个聚类组；3条无家族注释，1条有核查标记。带标记不等于标签错误；未标记也不等于标签可靠。

探索分析并非机制证明，不应以这些特征或历史测试结果继续反复选参数。优先检查同标签、相近背景的 C→D 纠错与添错样本及可靠性，再在分组隔离且严格嵌套的数据上验证候选方案。整体 D 对 C 的变化也可能受到独立 Platt 校准影响，不应全部归因于专项对比损失。
